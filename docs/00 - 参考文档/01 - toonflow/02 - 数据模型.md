# Toonflow 数据模型

> 分析对象：`refer/Toonflow-app-master`（新版 v1.1.8，26 张表）
> 分析日期：2026-08-09
> 文档说明：本文档以**逐表逐字段**粒度梳理新版 Toonflow 的完整数据模型，包含字段类型、约束、初始数据、演进增量与关系。

## A. 持久化机制

- 底层 **SQLite**，通过 **Knex** 操作，文件位置：Electron 走 `userData/db.sqlite`，否则 `cwd/db.sqlite`（见 `src/utils/db.ts`）
- schema 由**两处维护并存**：
  1. `src/lib/initDB.ts`：定义全部表结构与初始化数据。遍历 `tables` 数组，`hasTable` 判断，表不存在才建
  2. `src/lib/fixDB.ts`：每次启动执行增量修正（`addColumn` / `dropColumn` / `alterColumnType`）
- **主键约定**：多数表 `integer("id")` + `primary` + `unique`，依赖 SQLite `INTEGER PRIMARY KEY` 隐式自增；部分关联表用**复合主键**（storyboardId+assetId）；`memories`/`o_vendorConfig`/`o_skillList` 用**文本主键**（UUID）
- `database.d.ts` 由脚本在 dev 模式逆向生成，反映 fixDB 执行后的最终结构

## D. 初始数据

1. **`o_user`**：默认用户 `admin`
2. **`o_agentDeploy`**：预置 20+ 项 Agent 模型配置
3. **`o_setting`**：预置 tokenKey、memoryConfig 等设置项
4. **`o_prompt`**：预置事件提取、剧本资产提取、视频提示词等初始提示词
5. **`o_vendorConfig`**：默认启用 Toonflow 官方供应商
6. **`o_skillList`**：预置多个技能模块初始内容

## E. 演进增量（fixDB 后添加）

1. `o_prompt` 新增 `useData` 字段
2. `o_agentDeploy` 新增 `type`、`temperature`、`maxOutputTokens` 字段
3. `o_assets` 新增 `audioBindState` 字段
4. `o_modelPrompt` 新增 `fileName`、`path` 字段
5. 新增 `o_assetsRole2Audio` 关联表

## F. 表关系

```
o_project 1─n o_novel 1─n o_eventChapter n─1 o_event
o_project 1─n o_script 1─n o_assets
o_script n─n o_assets  (o_scriptAssets)
o_assets 1─n o_image
o_script 1─n o_storyboard n─n o_assets (o_assets2Storyboard)
o_storyboard n─n o_assetsRole (o_assetsRole2Audio) n─1 o_assetsAudio
o_project 1─n o_videoTrack / o_video
o_project + episodesId → o_agentWorkData (scriptAgent/productionAgent)
o_agentDeploy ── 分配 ──> scriptAgent / productionAgent
memories ── isolationKey 隔离 ──> 各 Agent
```

逻辑外键为主（无物理 FOREIGN KEY 约束）。

## G. 潜在问题

1. **apiKey 明文存储**：`o_vendorConfig.inputValues` 含明文 apiKey，`o_setting.tokenKey` 明文，安全性弱
2. **JSON 字段无约束**：`o_agentWorkData.data`、`o_assets.prompt`、`o_setting.value`、`o_novel.event` 等大量 JSON 序列化字段，schema 演进靠约定
3. **文本/UUID 主键**：`memories`、`o_vendorConfig`、`o_skillList` 用文本主键，无物理外键
4. **复合主键关联表**：`o_scriptAssets`/`o_assets2Storyboard`/`o_assetsRole2Audio` 用业务复合主键，更新需先删后插
5. **无物理外键**：全库依赖逻辑引用，删除级联需业务代码保证（如删项目需手工清关联表）
6. **表名演进**：旧版 `t_` 前缀 → 新版 `o_` 前缀，`t_taskList`→`o_tasks`、`t_prompt`→`o_prompt`（单数），迁移需注意
