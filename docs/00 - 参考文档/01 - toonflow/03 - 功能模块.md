> 文档说明：本文档独立梳理新版 Toonflow 的所有功能模块，包含模块总览与每个模块的完整接口清单（方法、参数、功能说明）。业务流转见《04 业务流程》，表结构见《02 数据模型》，智能体见《05 智能体模块》，导演台画布见《06 导演台画布》。

## A. 功能模块总览

新版路由由 `src/core.ts` 自动扫描生成（文件名即路由，子目录即子路径）。按业务域划分为 **20+ 个路由模块**：

| 模块 | 路由前缀 | 功能定位 |
|---|---|---|
| login | `/login` | 用户登录 |
| project | `/project` | 项目、画风、导演手册、视觉手册管理 |
| general | `/general` | 项目统计/查询/更新 |
| novel | `/novel`（含 `/novel/event`） | 小说原文、事件提取 |
| script | `/script` | 剧本 CRUD、资产提取、导出 |
| scriptAgent | `/scriptAgent` | 剧本智能体工作区数据 |
| assets | `/assets` | 资产生成、素材、音频、轮询 |
| assetsGenerate | `/assetsGenerate` | 资产提示词润色与图片生成 |
| cornerScape | `/cornerScape` | 角色场景/音频绑定 |
| production | `/production`（含 assets/editImage/storyboard/workbench） | 导演台画布全流程 |
| artStyle | `/artStyle` | 画风预设 |
| modelSelect | `/modelSelect` | 模型选择 |
| agents | `/agents` | Agent 记忆读取/清理 |
| task | `/task` | 任务中心 |
| setting | `/setting`（含大量子域） | 系统设置（供应商/Agent部署/技能/数据库/登录/记忆/提示词等） |
| common | `/common` | 通用（大图） |
| other | `/other` | 其他（清数据/版本） |
| test | `/test` | 测试 |

## B. 通用约定

1. **鉴权**：除 `/login/login` 外，所有接口需 `Authorization: Bearer <token>`（JWT，tokenKey 来自 `o_setting`）
2. **方法**：RESTful 增删改查类接口均为 **POST**，纯查询多为 GET（但部分查询也用 POST，以实际为准）
3. **请求体**：JSON，经 `validateFields`（zod）校验
4. **异步任务**：生成类接口返回 taskId，前端轮询 polling 接口
5. **AI 对话**：scriptAgent/productionAgent 走 socket.io `/api/socket/*`

## G. 模块设计要点

1. **约定式路由**：文件名即路由、子目录即子路径，新增接口零配置
2. **AI 对话独立于 REST**：scriptAgent/productionAgent 走 socket.io，REST 仅做数据 CRUD
3. **异步任务贯穿**：资产生成、分镜图、视频、提示词均异步 + 轮询 + taskRecord
4. **设置域最庞大**：vendorConfig/agentDeploy/skillManagement 支撑"厂商可配置 + Agent 可部署 + 技能可插拔"三大能力
