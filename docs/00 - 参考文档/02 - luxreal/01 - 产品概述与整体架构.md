## A. 产品定位与简介

### 001 官方Slogan与定位
- 主Slogan：**极致一致性的 AI短剧流水线**
- 副Slogan：基于3D世界模型，全流程可高效编辑
- SEO关键词：AI短剧、AI短剧制作、AI视频生成、短剧制作工具、AI视频一致性、短剧自动化、AI漫剧、电商视频生成
- SEO描述：LuxReal AI短剧生产线，基于3D空间智能实现角色、场景、道具一致性，从剧本解析到成片导出，全流程闭环，助力专业短剧团队效率提升

### 002 目标用户
- 专业短剧创作团队（如琥珀影业、瀚博金达等头部团队）
- 新锐出海短剧工作室
- 电商运营团队（产品营销视频生成）
- 独立短剧导演与创作者

### 003 核心价值主张（三大卖点）
| 卖点 | 主标题 | 副标题说明 |
|------|--------|------------|
| 一致性 | 场景角色一致 / 绝不变形 | 基于3D世界模型，跨镜跨集保持角色场景100%一致 |
| 高效率 | 丝滑出片 / 告别漫长制作周期 | 一键生成模式，单条15秒视频仅耗时6分钟，效率提升10× |
| 低成本 | 成本更低 / 大片质感小成本 | Seedance2.0低至0.49元/秒（会员首购价），制作成本降低70% |

### 004 产品应用场景
- 短剧制作（核心场景）：从剧本到成片的全流程短剧流水线
- 电商产品视频：单图快速建3D片场，生成产品广告视频
- 社交媒体营销短视频
- 漫剧/动画内容生成

## B. 技术栈与模型体系

### 005 核心模型矩阵（自研 + 集成）
| 类别 | 模型名称 | 说明 | 可选规格 |
|------|----------|------|----------|
| **视频生成模型** | Seedance 2.5 | 主视频模型，VIP，30秒长镜直出，50个多维参考，局部精修可控，11种语言适配 | 480P / 720P / 1080P |
| 视频生成模型 | Seedance 2.0 Fast | 快速版，低积分成本 | 480P / 720P |
| 视频生成模型 | Seedance 2.0 | 稳定版 | 480P / 720P / 1080P |
| 视频生成模型 | KlingO3 | 第三方集成（可灵） | 720P |
| **角色图像生成模型** | Lux Banana 2（自研） | 角色一致性专用图片模型 | 1K / 2K / 4K |
| **场景图像生成模型** | Lux Banana 2（自研） | 场景生成专用图片模型 | 1K / 2K / 4K |
| 道具图像生成模型 | Lux Banana 2（自研） | 道具图片生成 | 1K / 2K / 4K |
| 通用图片模型 | Lux Image 2 | 通用图片生成 | 1K |

### 006 三大核心引擎（技术架构亮点）
1. **3D片场引擎**：单图快速建片场，机位场景自动对齐，保证多镜头空间一致性
2. **智能镜头库引擎**：基于剧本叙事，自动生成连续镜头序列（HeroShotGroup），导演级分镜脚本
3. **自定义技能库引擎**：技能模版预设，流水线批量生产，支持Agent技能配置

## D. 全局导航体系与通用组件

### 009 左侧主导航（Home Sider）
所有登录后页面共享同一侧边栏（Home-nav / Home-sider）：
```
┌─────────────────────────┐
│  ✨ 创作     (active)   │
│  👀 发现               │
│  📁 作品               │
│  🔔 消息  (0)          │
│  💎 充值               │  ← 顶部Banner位也有
└─────────────────────────┘
```
- 位置：固定左侧垂直导航
- 功能：快速切换三大核心模块 + 消息 + 充值快捷入口

### 010 工作台顶部进度导航（Step Bar）
短剧Agent工作台特有，4步流程切换器：
> 剧本拆分 → 资产生成 → 视频制作 → 成片预览  
> 右侧辅助功能：创建/进入自由画布（Beta 高亮按钮） | Agent 技能配置

### 011 工作台左侧剧集大纲导航（Outline）
结构：
- 第1集 - {集名}（默认展开）
  - 叙事单元 1 | {标题}
  - 叙事单元 2 | {标题}
  - 叙事单元 3 | {标题}
  - 叙事单元 4 | {标题}
- 第2集 - {集名}（可折叠）
- 第3集 - {集名}（可折叠）
- + 新增剧集 按钮

### 012 全局 Banner 公告条
- 全站顶部固定滚动公告（如："Seedance 2.5 已上线！30 秒长镜直出，50 个多维参考，局部精修可控，11 种语言适配。"）

### 013 通用组件（UI设计系统）
使用自研 TUI 组件库（类前缀 `tui-`）：
- `tui-btn` 按钮体系（primary/secondary/strength/size多维度）
- `tui-tabs` 胶囊式 Tab 栏 + Divider 样式
- `tui-dialog` 全屏/普通弹窗
- `tui-icon` SVG 图标系统
- `tui-text-overflow` 文本溢出省略
- `tui-scrollbar` 自定义滚动条
- `ProjectCard` 项目卡片组件（复用在创作页示例 & 作品页列表）
- `ElementEditorCard` 资产编辑器卡片（角色/场景/道具共用）
- `StickyScrollSpyPanel` 右侧滚动锚点配置面板

### 014 全局视觉风格
- **主题配色**：深色模式（Dark Mode）为主，蓝紫色霓虹渐变点缀（与logo光效一致）
- **字体**：无衬线现代字体
- **视觉元素**：大量渐变光影背景 + 人物剪影构图 + 玻璃态卡片

## F. 补充与修正（来自06号全面审查文档）

### 015 Agent体系自研双LLM模型（⭐核心架构补充：原文档完全遗漏）
除了已公布的视频生成模型（Seedance系列/KlingO3）和图片生成模型（LuxBanana2/LuxImage2），LuxReal在Agent幕后还藏有**两个自研大语言模型**，这是整个Agent流水线的大脑：
- **Lux Chat 5.2**：分镜脚本生成引擎，负责剧本拆分、智能扩写、8字段标准分镜输出
- **Lux Gem 3.0**：单视频提示词润色引擎，负责在视频生成前将提示词优化为视频模型友好的格式

### 016 Agent技能配置4个Tab总览
Agent技能配置面板为4Tab模块化结构：
①基础参数配置 ②分镜脚本生成技能（LuxChat5.2驱动） ③视频任务规划技能（含多宫格Pro/Fast两种智能镜头算法） ④单视频提示词润色技能（LuxGem3.0驱动）

### 017 双向流转入口具体位置
「创建/进入自由画布 Beta」按钮位于**工作台顶栏StepBar（剧本拆分→资产生成→成片预览）的正右侧**，与「Agent技能配置」按钮并列，一键从Agent流水线转入自由画布精修。
