## A. 创作入口页（/create-video）详解

### 015 页面布局总览
```
┌─────────────────────────────────────────────────────────────┐
│ [全局公告 Banner] Seedance 2.5 已上线！ ...                 │
├──────┬──────────────────────────────────────────────────────┤
│ 侧栏 │ [创作模式Tab Bar] 短剧 Agent（Beta） | 自由画布     │
│      ├──────────────────────────────────────────────────────┤
│ 创作 │ [剧本上传区] 拖放区 + 粘贴文本框 + 使用示例剧本     │
│ 发现 │ ├────────────────────────────────────────────────────┤
│ 作品 │ [快捷配置条] 风格预设 | 模型配置 | 分辨率 | 比例   │
│ 充值 │ │ 时长自动 | Agent技能配置 | [进入工作台 ▶]         │
│      │ ├────────────────────────────────────────────────────┤
│      │ [3个官方案例卡片] ProjectCard × 3                    │
│      │ ├────────────────────────────────────────────────────┤
│      │ [模型配置详情面板] 右侧 Sticky 滚动锚点面板         │
│      │ ├────────────────────────────────────────────────────┤
│      │ [精选推荐区] 3张Banner卡片（会员/画布/教程）        │
└──────┴──────────────────────────────────────────────────────┘
```

### 016 两大创作模式 Tab
| Tab | 名称 | 标识 | 适用场景 |
|-----|------|------|----------|
| 1 | 短剧 Agent | Beta 标记 | 标准剧本驱动，全自动流水线，适合批量生产 |
| 2 | 自由画布 | Beta 标记 | 手动编排、局部精修、关键片段打磨，适合精品打磨 |

### 017 剧本上传区（核心入口）
组件路径：`ShortFormEntry-*`
- **方式一**：拖拽上传剧本文件（支持 .docx / .pdf 等，示例："三界跪迎，魔尊归位_剧本.docx"、"月落昭华_剧本.pdf"）
- **方式二**：直接粘贴剧本文字（限制：不超过5万字）
- **方式三**：点击"使用示例剧本开始创作体验" → 弹出3个官方教学案例选择 → 直接克隆进入工作台

### 018 快捷配置条（Quick Config）
位于剧本区底部，模型配置摘要：
| 配置项 | 默认值 | 可选值 |
|--------|--------|--------|
| 风格预设 | 通用写实 | （下拉选择其他风格） |
| 分辨率 | 480P | 480P / 720P / 1080P |
| 视频比例 | 9:16 | 16:9 / 1:1 / 9:16 |
| 每集时长 | 自动 | 自动 / 1分钟 / 1-2分钟 / 2-3分钟 / 3-5分钟 / 5-10分钟 |
| 其他按钮 | — | **Agent 技能配置**（弹层）、**进入工作台**（主CTA） |

### 019 三个官方教学案例卡片
组件：`ProjectCard`（与作品页列表卡片复用组件）
| 序号 | 案例名称 | 类型 | 用途 |
|------|----------|------|------|
| 1 | 【LuxReal官方教学案例】一语成谶：市井说书人的谎言局 | 古装悬疑说书 | 完整的古装多角色多场景范例 |
| 2 | 【LuxReal官方教学案例】合租上司是心动对象 | 现代都市情感 | 现代职场生活范例 |
| 3 | 【LuxReal官方教学案例】疼痛银行 | 现代都市奇幻 | 新概念设定范例 |

每张卡片右上角有三点 `edit` 图标 → 点击直接进入该项目的Agent工作台。

### 020 右侧模型配置面板（Sticky + ScrollSpy）
组件：`StickyScrollSpyPanel`

7个Tab分类：**视频 / 角色图片 / 场景图片 / 道具图片**（胶囊式），每个Tab下多组参数：

**[Tab：视频] 视频生成参数：**
| 参数 | 选项 |
|------|------|
| 视频生成模型 | Seedance 2.5 VIP（默认）/ Seedance 2.0 / Seedance 2.0 Fast / KlingO3 |
| 视频生成分辨率 | 480P / 720P / 1080P |
| 视频比例 | 16:9 / 1:1 / 9:16 |
| 每集时长 | 自动 / 1分钟 / 1-2分钟 / 2-3分钟 / 3-5分钟 / 5-10分钟 |

**[Tab：角色图片] 角色图像生成参数：**
| 参数 | 选项 |
|------|------|
| 角色图形生成模型 | Lux Banana 2 |
| 图片生成分辨率 | 1K / 2K / 4K |
| 图片比例 | 16:9 / 1:1 / 9:16 |

**[Tab：场景图片 / Tab：道具图片]**
与角色图片参数结构完全一致，模型同样为 Lux Banana 2。

### 021 底部精选推荐区（3张Banner卡片）
每张卡片带一个"立即开通/查看"按钮：
1. **会员月卡特惠卡**：首购5折！Seedance2.0 低至 0.49元/秒 → 跳转充值订阅页
2. **自由画布 Beta 上线卡**：流水线一键转画布，关键片段自由精修 → 跳转自由画布模式
3. **新手教程卡**：跟随引导，轻松掌握创作流程 → 跳转教学文档/视频

## B. 发现页（社区广场）/ai-video

### 022 页面结构
- 顶部：左侧主导航（发现为 active 态）
- 主体：瀑布流/网格布局的作品展示墙（HTML Size 1.2MB，内容使用虚拟列表懒加载）

### 023 作品类型构成（从图片alt推断）
**短剧类（unnamed作品为主）：** 大量官方/用户创作短剧封面
**电商产品类（material视频）：** hamburger（汉堡）、handcream（护手霜）、armchair（扶手椅）、gloden hour（金光场景）、Lounge Chair（躺椅）、necklace（项链）、Helmet（头盔）、Table lamp（台灯）、handbag（手提包）、Milk ad（牛奶广告）、perfume（香水）、Floor Lamp（落地灯）、milk（牛奶）、vase（花瓶）、Over-ear wireless headphones（头戴耳机）、ring（戒指）、bed（床）、Layered Portable Baby Care Organizer Caddy（母婴收纳盒）等

> 亮点：产品不仅服务短剧创作者，同时覆盖电商团队的产品营销视频需求，用同一套3D片场引擎做双市场。

## C. 作品管理页 /my-projects

### 024 三个子Tab结构
组件：`ProjectCard` 卡片复用
```
┌──────────────────────────────────────────────┐
│  [项目]  [画布]  [视频成片]                   │  ← 3个顶部Tab
├──────────────────────────────────────────────┤
│  ┌──────────┐ ┌──────────┐ ┌──────────┐    │
│  │ 疼痛银行 │ │ 合租上司 │ │ 一语成谶 │    │  ← ProjectCard 网格列表
│  │ 时间戳   │ │ 时间戳   │ │ 时间戳   │    │
│  │ (封面图) │ │ (封面图) │ │ (封面图) │    │
│  └──────────┘ └──────────┘ └──────────┘    │
│                    ...更多卡片...            │
└──────────────────────────────────────────────┘
```

### 025 三个Tab详细说明
| Tab名 | 路由query（推断） | 内容说明 |
|--------|------------------|----------|
| 项目 | `?type=Project` | 短剧 Agent 创建的完整项目（多集多叙事单元） |
| 画布 | `?type=Canvas` | 自由画布创建的项目（Beta模式产出） |
| 视频成片 | `?type=Video` | 最终合成导出的成片视频，可下载管理 |

每张卡片：
- 顶部：背景缩略图（项目封面）+ 渐变蒙版
- 中部：项目标题（单行溢出省略）+ 创建时间
- 右下角：三点悬浮操作按钮 → 点击直接进入对应工作台

```

│  └──────────────┴──────────────┘                    │

│  │+86│                                               │
│  └─┘ 请输入验证码                                    │
│                                                      │
│  [ 登录/注册 ]                                       │  ← 一键完成注册+登录
│                                                      │
│  我已阅读并同意 用户条款 & 隐私政策  [✓]             │
└─────────────────────────────────────────────────────┘
```

### 027 登录特点
- 默认 Tab：手机号 + 验证码登录（无密码）
- 登录与注册合一：同一个按钮完成新老用户识别
- 支持切换"账号密码"方式（适合企业/团队）
- 区号默认 +86（推测支持其他区号）
