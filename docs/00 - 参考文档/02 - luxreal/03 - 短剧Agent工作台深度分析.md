## B. Step 1：剧本拆分（/script）

### 032 功能目标
将原始剧本自动化拆分 → **集 → 叙事单元(Beat) → 场景**三级结构，并允许人工编辑精修。

### 033 叙事单元卡片结构（BeatCard × N）
每个叙事单元一张垂直卡片：
```
┌───────────────────────────────────────────────────────────┐
│ 「叙事单元 X」 {标题}                        [状态徽章]      │
│                                              视频制作中     │
│  本集预设总时长：[自动 ▾]                    [返回查看]      │
│  [删除]  [剧本原文 ▼ 展开]                                   │
├───────────────────────────────────────────────────────────┤
│  【场景1：{地点名} — {日/夜}】                               │
│  ▲{镜头/环境描述}（可编辑文本框 BeatScriptSegment）        │
│  角色A：{对话台词}                                          │
│  ▲{镜头描述}                                                │
│  角色B（{动作提示}）：{对话}                                │
│  （可继续向下扩展更多【场景X】区块）                        │
└───────────────────────────────────────────────────────────┘
```

### 034 剧本拆分标记语法（自动识别规则）
| 标记 | 含义 | 样式 |
|------|------|------|
| 【场景X：地点 — 时间】 | 场景切换 | 加粗标题按钮 |
| ▲ + 描述 | 镜头/环境/动作描述 | 正文段落段首符号 |
| 角色名（动作提示）：台词 | 角色对白 | 结构化 |
| （画外音） | 画外音角色 | 括号角色修饰 |

### 035 本集操作按钮
- `+ 新增剧集`：在项目下增加新的一集
- 时长下拉：本集预设总时长（自动/1分钟/1-2分钟/.../5-10分钟）

## C. Step 2：资产生成（/assets）

### 036 功能目标
从拆分完的剧本自动提取：**角色 / 场景 / 道具 / 智能镜头 / 通用素材** 五类资产，并为每个资产生成一致性参考图片（或手动上传）。

### 037 六类资产分类 Tab
```
[概览] [角色] [场景] [道具] [智能镜头] [通用素材]
└─ + 搜索框：「请输入」
```
概览页：5类资产全部混合展示，提供资产全图快速浏览。

### 038 顶部工具栏按钮
| 按钮 | 功能 |
|------|------|
| 3D 片场 | 进入3D空间场景对齐界面（保证镜头机位一致性） |
| 添加 | 手动新增资产（角色/场景/道具） |
| 重新提取本集资产 | 从当前剧本重新跑一次 NLP 提取流程 |
| 批量生成资产图 | 对未生成图的资产一键批量出图 |

### 042 智能镜头（HeroShotGroup）
这是**最有价值的独特点**：Agent从剧本中自动识别出"高光片段"并预先构建好镜头组方案，包含机位、景别、运镜。
案例中生成的8个智能镜头组：
- 第1集-叙事单元1-HeroShotGroup / 古街说书开场片段
- 第1集-叙事单元2-HeroShotGroup（×2条）
- 第1集-叙事单元3-陆言数钱藏钱遇异响
- 第1集-叙事单元4-HeroShotGroup（×2条）/ 陆言夜居遇捕头造访

### 043 通用素材
平台公共素材库：用户上传/系统提供的通用参考PNG图片，命名为NH****格式ID。

### 044 资产引用优化提示
面板底部提示：**"功能优化：不用@资产，描述即可生效"**
- 简化模式：自然语言描述中提到角色名/场景名即可生效（模型自动匹配引用）
- 精准模式：使用`@`显式指定素材用途（更可控）

## D. Step 3：视频制作/分镜脚本（/storyboard）

### 045 功能目标
核心生产力步骤！从叙事单元自动生成**电影级分镜脚本**，每个分镜包含详细的镜头参数，可人工编辑、重规划、触发视频生成。

### 046 叙事单元分镜页结构（以"叙事单元1 陆言开场说书"为例）
```
叙事单元1：陆言开场说书（总时长50秒）
├── 历史版本 [查看]
├── [重新规划]  [生成视频]  [剧本原文 展开]
├── 分镜1 成片 10s（早点摊老板掀开蒸笼）
│   ├─ 参考图列表（可拖拽）：[早点摊蒸笼图] [算命卦幡图]
│   └─ 分镜脚本正文（可编辑文本框）：
│      镜头1：【时长3s】【景别中景】【运镜慢慢推进】【视角平视】
│             【主体】早点摊老板掀开蒸笼冒出白汽...
│             【背景】市井古街
│             【台词】包子店老板吆喝：卖包子喽！！！
│             【环境音】嘈杂的中国古代市井小巷背景音
│      镜头2：【时长2s】【景别近景】【运镜固定】【视角平视】
│             ...
│      镜头3：...
│      镜头4：...
│      严格按照分镜脚本进行生成，参考上传图的人物形象、场景和道具。不要生成字幕。
├── 分镜2 成片 13s（陆言站在破旧木凳子）
│   ├─ 参考图 × 4（陆言铜锣/围观者/折扇醒木）
│   └─ 4 个镜头（含景别/运镜/视角/主体/台词/环境音）
│      └─ 尾句约束指令：严格按分镜脚本进行生成...不要生成字幕。
├── 分镜3 成片 14s
│   ├─ 参考图 × 2
│   └─ 2 个镜头
├── 分镜4 成片 13s
│   ├─ 参考图 × 4（陆言/铜钱/地痞男 + 2个资产@）
│   └─ 3 个镜头
└── 本集汇总：127秒
```

### 047 专业分镜脚本字段模板（Agent输出格式）
每个镜头的**标准8字段**：
| 字段 | 说明 | 典型值 |
|------|------|--------|
| 【时长】 | 单镜头秒数 | 2s / 3s / 4s / 5s / 9s |
| 【景别】 | 摄影机距离 | 特写 / 近景 / 中景 / 全景 / 远景 |
| 【运镜】 | 镜头运动方式 | 固定 / 慢慢推进 / 横移跟拍 |
| 【视角】 | 拍摄角度 | 平视 / 微仰拍 / 俯拍 / 过肩 / 平视侧面 / 平视正面 |
| 【主体】 | 画面描述（最核心） | 含人物动作、表情、道具互动，长达百字 |
| 【背景】 | 环境/场景名 | 市井古街 / 老槐树下 / 茶馆门槛 |
| 【台词】 | 角色对白 | 【角色名】情感修饰：台词内容 |
| 【环境音】 | 音效设计 | 铜锣"当当当"回响、人群脚步靠近、窃笑声 |

### 048 分镜卡关键操作
- **历史版本**：查看该叙事单元的历史生成版本（可回溯）
- **重新规划**：让Agent重新生成分镜脚本方案（不满意时重来）
- **生成视频**：按当前分镜脚本调用视频模型出片
- **编辑镜头库**：每张分镜卡的操作按钮，深度编辑该镜头组细节
- **剧本原文展开**：查看/对照原始剧本段落

### 049 参考图拖拽区域（Draggable）
Snapshot显示大量`draggable`元素，每个分镜卡可自由拖入：
- 资产参考图片
- 资产@引用标签（例：`陆言-市井说书装` 是陆言-市井说书装）

### 050 全局约束指令
每个分镜脚本结尾，Agent自动追加的LLM约束指令：
> "严格按照分镜脚本进行生成，参考上传图的人物形象、场景和道具。不要生成字幕。"

## F. 自由画布 Beta（一键转入）

### 054 产品定位
> 体验短剧"爆款"的全新打法

### 055 设计哲学
- Agent流水线：**批量、高效、标准化** → 前90%内容
- 自由画布：**精修、打磨、创意发散** → 最后10%的"爆款关键片段"

### 056 核心功能（从弹窗信息与路径推断）
1. **任意环节一键转入**：在短剧Agent 4步的任何节点，点击顶栏「创建/进入自由画布 Beta」按钮即可转入
2. **重点片段精修**：特别针对「钩子（前3秒）」「前三集」「关键镜头」展开精细化编排
3. **多方案A/B测试**：自由尝试多种分镜方案，比较选出最"抓人"的版本
4. **流水线↔画布双向流转**：Agent流水线可一键转画布，画布也可回传至流水线继续合成

### 057 为什么独立成模式？
- 创作过程双模式并存：**工业化量产** vs **手艺人打磨**
- 降低决策压力：用户不必一开始就选择"全自动"还是"手动"，可随时切换
- 解决"AI一致性高但不够爆款"的痛点：全自动偏稳，爆款需要微操

## G. Agent 技能配置面板

### 058 技能体系定位
类似自定义"导演风格模板"、"叙事模板"、"镜头语言模板"。面板位于工作台StepBar右侧，独立4Tab结构。

### 059 四个Tab真实详情（⭐审查实得，原文档此处为推断）

**Tab1：基础参数配置**（=创作页"模型配置"面板等价）
- 画面风格：风格库下拉联动（默认通用写实）
- 视频生成：模型 Seedance2.5 VIP | 分辨率 480P/720P | 比例 16:9/1:1/9:16 | 每集时长 自动/1min/1-2min/2-3min/3-5min/5-10min
- 三类资产图独立参数：角色/场景/道具 均为 Lux Banana 2 | 1K/2K/4K | 16:9/1:1/9:16

**Tab2：分镜脚本生成技能（核心引擎 = Lux Chat 5.2）**
- 说明：按时长预设将剧本原文转换为包含详细镜头描述的分镜脚本
- 「智能扩写」开关（⭐推荐开启）：优化为更适合视频生成的镜头描述
- 生成模版：默认「剧情细腻刻画」，可管理/可新建
- 生成模型：**Lux Chat 5.2**（自研LLM，首次披露）
- 另存为：用户改好后可另存为个人自定义模板
- 高级：生成逻辑、预期镜头格式（可微调）

**Tab3：视频任务规划技能**
- 说明：将分镜脚本编排为多个视频生成任务，预备好提示词+参考图
- 镜头规划模版：默认「剧情连贯编排」
- ⭐**智能镜头两种模式对比**：
  | 模式 | 原理 | 适用场景 | 资产限制 |
  |------|------|---------|---------|
  | 多宫格 Pro（推荐） | 生成连续视频后提取关键画面帧，保持长镜头连贯 | 叙事性强的长镜头 | ≤9张 |
  | 多宫格 Fast | 生成多宫格拼图后拆分，确保多镜头画风高度统一 | 多人互动要求画风统一 | ≤10张 |
- 描述框：0/128 字符

**Tab4：单视频提示词润色技能（= Lux Gem 3.0）**
- 说明：智能优化单视频提示词
- 润色模版：默认「通用模板」
- 润色模型：**Lux Gem 3.0**（第二个自研LLM，首次披露）
- 润色规则与要求：高级自定义

### 060 与Toonflow Skill体系对比
- Toonflow：代码级技能（Typescript函数，调用工具，非常Engineer向）
- LuxReal：配置/模板级技能（4Tab无代码配置，两个自研LLM驱动），非常Creator向
- **产品定位差异**：Toonflow面向开发者和极客，LuxReal面向专业短剧创作者与团队
