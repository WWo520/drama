## C. 年卡 / 连续包月 / 积分包

### 068 连续包月（Auto-Renew）
- 路径：充值弹窗顶部第三个 Tab（与「年卡」「积分包」并列）
- 机制：首月 5 折后每月自动续费扣款，用户可随时取消
- 推测价格梯度与普通月卡原价一致（¥70/¥700/¥1,960/¥4,900）

### 069 年卡（Yearly Plan）
- 路径：充值弹窗顶部第一个 Tab
- 特点：推测一次性预付 12 个月费用，享更大折扣
- 常见行业模式：年卡 ≈ 月卡原价 × 10（送2个月）或更低折扣

### 070 积分包（Points Pack）
- 路径：充值弹窗顶部 Tab「积分包」
- 适用场景：月卡积分快用完，但不想升级档位 → 临时购买积分包补充
- 价格机制：按购买量阶梯定价，月卡等级越高额外加赠越多（见066）

## F. 商业化设计亮点分析

### 075 定价策略亮点
| 策略 | 具体设计 | 心理学依据 |
|------|----------|------------|
| **首购5折锚定** | 首月35元即可体验 | 降低决策门槛，新用户低成本试用 |
| **功能无差异** | 所有档位共享全部功能 | 避免"便宜版被阉割"的被剥夺感 |
| **积分单价递减** | 月卡越大，单位积分越便宜（0.07→0.063） | 鼓励大客户选择高档位，提高 ARPU |
| **双重加赠机制** | 首购限时加赠 + 续费买包叠加赠 | 让用户感觉"限时便宜不买亏了" |
| **公示对照表** | 直接告诉用户"你能生成多少秒"，而不是"有多少积分" | 用户对"积分"无感，但对"71秒视频"有清晰预期 |
| **双模式入口** | 基础月卡(¥35入门) × 旗舰月卡(¥4900专业) | 兼顾个人创作者与团队客户 |
| **去水印权益全员标配** | 甚至基础月卡也去水印 | 避免"输出的片子带自家logo"的低质感，保护专业用户形象 |

### 076 与 Toonflow 商业化模式对比
| 维度 | LuxReal | Toonflow（调研推断） |
|------|---------|---------------------|
| 计费单位 | 积分制（按次/秒/张消耗） | 推测类似积分 |
| 档位 | 4档月卡，跨度140倍(35-4900) | 档位较少 |
| 功能分层 | 全部功能开放，只限制积分 | 可能有高级功能限制 |
| 最低门槛 | 首月¥35低门槛 | 可能更贵 |
| 公开透明 | 模型积分消耗全表公示 | 可能不透明 |
| 年卡/连续包月/积分包 | 4种付费形态齐全 | 推测较少 |
