#### 113.3 HeroShotGroup 镜头块卡片结构
每个叙事单元内部，不是直接列"镜头1、镜头2…"，而是先拆成若干 HeroShotGroup：
```
叙事单元1（50s）
├─ 镜头块1「成片 时长 10s」：镜头1-3（早点摊→人流→算命先生）
├─ 镜头块2「成片 时长 13s」：镜头1-4（陆言敲锣→吆喝→人群→折扇醒木）
├─ 镜头块3「成片 时长 14s」：镜头1-2（说书骂富商→围观者反应）
└─ 镜头块4「成片 时长 13s」：镜头1-3（预言死亡→铜钱抛出→地痞挤上前）
合计：10+13+14+13 = 50s ✓
```
- 每个镜头块卡片有【成片】标签和其独立时长
- 每个镜头块可**单独生成预览**，不必等到整个叙事单元
- 镜头块前置参考图绑定：「陆言敲铜锣 是镜头1的参考图，陆言掏出铜锣 是镜头2的参考图…」——用户将图片拖到这个位置就完成了镜头-参考图的绑定

## F. 给05号文档新增的5条设计亮点与建议

### 121 新增设计亮点：27种风格库包含"导演风格致敬"
**做法**：公共风格里直接放了「王家卫美学」「徐克美学」「邵氏武侠」这些导演/年代风格名。  
**为什么好**：短剧行业用户（尤其是MCN公司）会说"我要王家卫风格"、"我要老港片质感"——LuxReal直接把行业黑话做成风格选项，省去用户反复写prompt的过程。  
**对我们的建议**：我们的风格预设库**第一批就必须包含至少3-5个「导演/大厂IP风格」选项**（哪怕只是别名映射到现有模型的LoRA组合也行），比如"郭敬明媚拉光影"、"宁浩黑色幽默"、"漫威饱和色"，名字要直白，让用户觉得"这工具懂行业"。

### 122 新增设计亮点：2种智能镜头模式（Pro vs Fast）的明确权衡
**做法**：视频任务规划里将多宫格算法拆成两种模式，用一句人话讲清楚差异：Pro连贯、Fast画风统一，各有资产关联限制。  
**为什么好**：把复杂的"多镜头一致性算法选型"从技术黑盒变成用户能理解的选择题。  
**对我们的建议**：不要只放一个"AI自动处理"。把用户能感知的差异枚举出来，用**一行说明+一个推荐徽章**帮用户选。

### 123 新增设计亮点：跨集复用资产不重复扣费
**做法**：批量生成弹窗里专门加了一句"资产参演的所有剧集都会显示该资产的生成状态（不会重复消耗积分）"。  
**为什么好**：80-100集的短剧里，同一个沈青禾角色会在每一集出现——如果每集都扣一次角色图生成积分，用户会炸。明确写出来不扣费，直接打消大客户的大额消费顾虑。  
**对我们的建议**：我们的积分计费系统在 V1 就要设计好**「资产指纹+复用免扣」机制**。同时必须把这句话写在计费规则最显眼处（批量生成弹窗顶部）——"跨集复用资产不重复扣积分"，这是短剧MCN选择平台的关键决策点。

### 124 新增设计亮点：道具图独立使用 1:1 正方形比例
**做法**：资产图参数里，角色/场景是 16:9，只有道具图是 1:1 正方形。  
**为什么好**：道具（铜锣、折扇）不需要场景上下留白，正方形能最大效率利用生成分辨率，避免"道具只占画面1/10"的浪费。  
**对我们的建议**：不要所有资产都用同一个比例。道具单独1:1，证件类用3:4，海报类用2:3——不同类型资产有各自最优分辨率比例。

### 125 新增设计亮点：Step3 分镜页的"历史版本"按钮（版本管理）
**做法**：每个叙事单元顶部都有历史版本，分镜脚本每一次重新规划都留档，用户可回滚。  
**为什么好**：AI输出是随机性的——"重新规划"出来的新分镜可能不如上一版。没有版本管理的话，用户就不敢点"重新规划"（怕点了就把好的弄没了）。  
**对我们的建议**：我们的智能分镜、Agent脚本拆分、资产重绘等所有"AI重新生成"的操作，**第一版就要带版本管理**，哪怕只保留最近3个版本也行。这是"敢不敢用"的信心问题。
