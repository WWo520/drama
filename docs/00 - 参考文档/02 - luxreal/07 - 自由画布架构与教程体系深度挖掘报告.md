# 07 - 自由画布架构与教程体系深度挖掘报告

> **文档定位**：本报告为第三次深度交互挖掘的产物。针对用户明确要求的「短剧工作台深入操作 / 自由画布内部 / 新手教程 + 飞书教程 + 视频教程」三大方向进行逐项手动点击验证。核心发现：
> 1. **自由画布的真实形态不是时间线视频剪辑器，而是节点式可视化工作流编辑器（类 n8n / LangFlow 低代码形态）**——这是架构级认知的颠覆性修正
> 2. **3D 片场 = 实时渲染页面**，内部为「场景 Tab + 光影 Tab（环境/灯光/滤镜）」的双引擎结构
> 3. Step3 叙事单元头部「历史版本 / 重新规划 / 生成视频」三按钮结构 + 重新规划弹窗内「分镜脚本 / 重生成分镜」双 Tab 首次曝光
> 4. 教程体系四级分层：创作页 Banner 新手引导 → 首页 Landing 20 秒 4 步教程 → 画布内双帮助（快捷键+Help）→ 首页完整 FAQ + 行业深度测评文

### 105. 3D 片场内部结构 = 实时渲染双引擎页面（颠覆性新发现，URL: `/create`）
点击 Step2 顶部「3D 片场」按钮后，跳转到独立页面（标题：**实时渲染**），页面异常时会显示大字：「**3D 片场 启动失败 [重新启动]**」。

**完整结构如下：**
```
┌─ 实时渲染 页面 ─────────────────────────────────────────┐
│  顶部大 Tab： [场景]  [光影]                            │
│   ├─ 光影 Tab 下子 Tab：[环境]  [灯光]  [滤镜]          │
│   └─ 右侧属性子 Tab：[风格]  [时段]  [更多]            │
│                                                          │
│  光影模板分类维度：风格 / 色系 / 空间类型 / 亮度          │
│                                                          │
│  输出模式：[普通图]  [全景图]   生成  [16:9 ▼]          │
└──────────────────────────────────────────────────────────┘
```
- **架构意义**：3D 片场不是「3D 建模工具」，而是「**场景/光影的实时渲染参考图生成器**」——用户在虚拟影棚走位取角度、调光影环境色，最终出 **普通图 / 全景图** 两种参考图，回灌给 Step2 资产库作为参考锚点。这就是解决一致性的幕后引擎！

### 128. 进阶实战教程（从行业一线深度测评文章获取的最佳实践级教程信息）
这些虽非官方飞书文档，但为一线创作者实测教程级干货：

**a. 先流程、后画布——官方 Slogan 背后的工作流**
> Step1-4 Agent 流水线解决「从 0 → 70 分」（快，批量起量、快速试错）；
> 一键转自由画布解决「从 70 → 90-100 分」（精修核心镜头，调提示词/模型/光影）；
> 全程不跳软件，不倒文件。

**b. 智能镜头预演机制教程——一致性核心解法**
> 1. 先基于完整剧本跑一段「预演视频」（排演预览）
> 2. 从预演中抽关键帧 → 成为全局分镜锚点
> 3. 后续所有视频生成 **都以锚点为标准**（人物造型/场景/空间关系/光影/色调锁定）
> 4. 对比九宫格参考图：场景布局、人物站位完全一致，不崩
> 5. 接入 Seedance 2.5 后，预演覆盖最长 **30 分钟**全集级一致性

**c. 3D 创作台（3DGS 虚拟影棚）教学用法**
> 用 3DGS 技术把核心场景建成可自由走位的虚拟空间；
> 像在真实影棚一样「走路机位取景」，取任意视角生成参考图；
> 全程空间布局/物件/光影不崩，一致性靠 3D 空间坐标系天然保障。

**d. 三种 Agent 技能使用策略（进阶教程）**
> - 纯默认：新手直接用，全流程盲跑
> - 自定义润色：保留官方分镜/规划，只在「单视频提示词润色技能」里加自己的风格描述（最安全微调）
> - 全自定义：上传自己的技能包（给高级用户完全控制权）
