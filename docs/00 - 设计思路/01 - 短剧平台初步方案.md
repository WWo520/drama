# 短剧平台初步方案

> 说明：本文为功能级方案，按功能模块划分，区分**用户端**与**管理端**，不涉及具体技术实现。
> 基于《短剧平台思路》扩展，补充了原稿未覆盖的功能点（标注 ★）。

---

## 一、整体定位

建立一个围绕 **AIGC 短剧创作 + 内容分发 + 商业变现** 的一站式平台。

核心目标：
- 让创作者用较低的生成成本，完成"剧本 → 分镜 → 视频"的短剧生产闭环。
- 让产生的短剧内容能被发现、消费、互动，形成内容生态。
- 通过会员、套餐、算力计费，打通平台商业闭环。

核心角色：
- **创作者（用户端）**：使用平台完成创作、发布与管理作品。
- **运营管理者（管理端）**：管理用户、内容、计费、算力、智能体以及平台整体配置与运营。

---

## 二、平台端划分

| 端 | 说明 | 主要服务对象 |
|----|------|--------------|
| 用户端 | 创作者使用的前台，含空间协作、创作、发现、作品、个人中心等 | 创作者 |
| 管理端 | 后台运营管理，含用户、内容、计费、算力、配置等 | 平台运营 / 管理员 |
| 通用 / 底层 | 两端共用：登录鉴权、消息、通知、审计、权限等 | 两端共用 |

划分原则：用户端聚焦"创作与消费"，管理端聚焦"治理与运营"，通用能力下沉复用。

## 三、用户端功能模块

### 1. 账号与登录
**目的**：建立用户身份，保障账号安全，为后续创作与消费提供基础。

- **注册 / 登录**：支持手机号、邮箱、以及第三方账号方式登录；支持扫码登录。
- **找回密码**：通过手机 / 邮箱验证重置密码。
- **账号安全**：绑定手机号 / 邮箱、修改密码、登录设备管理、异地登录提醒。★
- **空间初始化**：用户首次登录后，自动为其创建一个默认（个人）空间，作为后续创作与协作的归属单位。★

### 2. 空间与团队协作 ★
**目的**：以"空间"作为协作与资源归属的基本单位，支持多用户共同创作与管理。

#### 2.1 空间管理
- **默认空间**：用户登录后自动创建个人默认空间，无需手动建。
- **空间列表 / 切换**：可拥有或加入多个空间，随时切换当前工作空间。
- **空间设置**：空间名称、头像、简介、对外可见性等维护。
- **空间配额**：空间的存储空间、成员数上限、算力额度等资源配额。

#### 2.2 成员管理
- **邀请成员**：通过账号 / 手机号 / 邀请链接 / 二维码，将其他用户拉入空间。
- **成员角色**：为成员分配角色（所有者 / 管理员 / 成员 / 仅查看）。
- **成员调整**：移除成员、变更角色、转让空间所有权。

#### 2.3 团队协作
- **共享创作**：空间内共享项目、资产、分镜、剧本等创作资源。
- **协作权限**：按角色控制谁能查看、编辑、提交生成、删除创作资源。
- **协作记录**：保留成员的操作与变更记录，便于追溯。★

### 3. 创作中心
**目的**：平台核心，承载从剧本到成片的完整创作流程。

#### 3.1 创作页 / 通用设置
**目的**：为一次创作（一部剧）配置全局基础参数，作为后续各环节的默认值。

- **画面风格库**：提供多种画面风格供选择与预览，作为整体视觉基调。
- **模型配置**：
  - 视频模型：模型、分辨率、比例、每集时长。
  - 角色图片：模型、分辨率、比例。
  - 场景图片：模型、分辨率、比例。
  - 道具图片：模型、分辨率、比例。
- **智能体技能配置**：选择并配置要启用的智能体技能（分镜脚本生成、视频任务规划、单视频提示词润色）。

#### 3.2 剧本拆分
**目的**：把一集剧本拆成更小的可执行单元，便于逐段生成与编排。

- **叙事单元**：每个单元包含名称、内容、状态（未开始 / 生成中 / 已完成 / 失败）、时长。
- **叙事单元管理**：
  - 自动拆分：按剧本自动切分为多个叙事单元。
  - 重新生成：对拆分结果不满意时重新生成。
  - 排序：自由调整单元顺序。
  - 本集预设时长：设定整集目标时长，辅助拆分比例。

#### 3.3 资产管理
**目的**：统一管理创作所需的角色、场景、道具、镜头与通用素材，供视频生成复用，保证角色 / 场景一致性。

- **概览**：各类资产的数量、占用、使用情况总览。
- **角色资产**：支持多角色；每个角色可维护多个形象与声音资产。
- **场景资产**：区分 2D 场景、3D 场景。
- **道具资产**：区分 2D 道具、3D 道具。
- **智能镜头资产**：支持从多种方式生成智能镜头，并为下一步视频生成提供镜头参考。
- **通用素材**：图片、视频、音频的通用素材库。
- **资产能力**：
  - 提取（描述）：从已有素材提取描述信息。
  - 生成资产图：基于描述生成资产图。
  - 重新上传 / 重新生成：对不满意的资产可替换或重建。
  - 资产管理：支持资产的增、删、改、查。

#### 3.4 视频制作
**目的**：把叙事单元逐步转化为可放映的视频成片，是创作的核心流水线。

- **叙事单元**：显示剧本名称、剧本内容（含历史版本）、关联资产。
- **分镜脚本**：一个叙事单元可对应多个分镜脚本；每个分镜包含镜头编号、时长、内容（一定格式的文本）。
- **视频生成参数**：选择分镜脚本、关联资产、以及视频配置后提交生成。
- **结果**：视频信息展示，支持历史版本留存与对比。
- **核心步骤**：
  1. 从叙事单元生成分镜脚本（可配置扩写剧本、生成模板、生成模型）。
  2. 从分镜脚本 + 关联资产生成视频。
- **后续能力**：
  - 成片预览：就地预览生成的视频。
  - 合成视频：多段视频合成为完整成片。
  - 导出工程文件：导出可复用的工程。
  - 其他功能：字幕擦除、手动抽帧。

#### 3.5 Agent 配置
**目的**：让创作者能够配置和控制创作中使用的智能体行为，实现可复用的创作能力。

- **基础参数**：
  - 画面风格（多种风格参考）。
  - 视频生成（T2V，支持多模型接入）。
  - 角色 / 道具 / 场景图像模型（T2I，支持多模型接入）。
- **分镜脚本生成技能**：配置生成模板（多模板管理）、生成模型（LLM，多模型接入）。
- **视频任务规划技能**：配置生成模板、生成模型。
- **单视频提示词润色技能**：配置润色模板、生成模型。

#### 3.6 自由画布
**目的**：以自由编排的方式组织创作流程（功能描述暂缺，待补充）。

- 可视化编排创作环节，灵活组合剧本、资产、分镜、视频生成等节点。

#### 3.7 剧集操作台（含页面 / 接口改造）
**目的**：对剧集生产与管理的操作界面进行改造，提升操作效率与一致性。

- 剧集操作台页面改造（原稿明确的改造需求）。
- 相关接口页面改造。

### 4. 作品管理
**目的**：统一管理创作产出，便于查看、继续创作与发布。

- **作品类型**：项目、画布、视频成片。
- **作品列表**：按状态 / 时间 / 类型 / 所属空间查看与检索。
- **草稿**：未完成作品的草稿箱，可随时继续编辑。
- **回收站**：删除作品可恢复或彻底删除，防止误删。
- **发布（可选）**：作品可选择是否发布到平台；发布需提交审核，状态流转为 未发布 → 待审核 → 已发布 / 已驳回。★
- **团队协作**：在所属空间内共享作品，按成员角色控制查看与编辑权限（见"空间与团队协作"）。

### 5. 任务与接单 ★
**目的**：让用户发布制作任务或承接任务，完成需求对接的意向登记（不涉及沟通与结算）。

#### 5.1 任务发布
- 发布任务：填写任务标题、描述、所需能力（剧本 / 分镜 / 视频制作等）、参考素材、期望周期等。
- 任务状态：草稿 / 发布中 / 已截止。
- 任务管理：编辑、上下架、查看收到的接单意向。

#### 5.2 接单与意向登记
- 任务广场：浏览、筛选、搜索平台公开任务。
- 我要接单：登记接单意向，提交个人能力简介与联系方式说明。
- 意向管理：查看自己发布任务收到的意向，以及自己登记过的意向。

#### 5.3 说明
- 仅做信息发布与意向登记，不涉及在线沟通与结算；双方由平台客服手动线下撮合。

### 6. 发现 / 内容消费
**目的**：让用户浏览、检索、消费平台上的短剧内容，形成内容生态。

- **视频信息流**：推荐流、按分类浏览、关键词搜索。★
- **详情页**：在线播放、简介、演员 / 角色信息。
- **互动能力**：评论、点赞、收藏、分享。★
- **关注 / 订阅**：关注创作者或剧集，获取更新。★
- **举报 / 反馈**：对违规内容进行举报。★

### 7. 消息中心
**目的**：集中触达用户各类消息，避免遗漏重要信息。

- 系统通知、创作进度 / 生成完成通知、评论与互动通知、审核结果通知、成员邀请 / 空间变更通知、套餐到期提醒等。★

### 8. 商业与会员
**目的**：实现平台商业化，让用户为算力、会员、内容付费。

- **充值页面与支付对接**：余额充值，对接多种支付方式。
- **套餐 / 会员 / 积分体系**：多种套餐与会员档位，积分获取与消耗。★
- **余额查询与管理**：查看余额、充值记录。
- **消费记录 / 账单明细**：记录每次消费，支持对账。★

### 9. 个人中心
**目的**：管理个人资料、账户、空间与平台偏好。

- **个人信息**：头像、昵称、简介等资料维护。
- **我的空间**：空间入口，跳转至"空间与团队协作"查看我拥有 / 加入的空间。★
- **存储空间管理**：账号与各空间的存储占用、扩容与购买。★
- **AIGC 水印**：设置内容标识与水印（合规要求）。★
- **语言切换**：多语言界面切换。
- **问题反馈**：提交问题与建议。
- **平台条款与协议**：查看服务条款、隐私政策等。
- **退出登录**。
- **我的创作数据 / 数据统计**：作品播放等数据。★
- **版权与授权管理**：管理作品版权与授权范围。★

### 10. 教学与帮助
**目的**：降低上手门槛，帮助用户完成创作与使用。

- **教学课程**：分主题的创作教学课程。
- **帮助中心 / FAQ**：常见问题的自助解答。★

## 四、管理端功能模块

### 1. 平台概览（Dashboard）
**目的**：让运营管理者快速掌握平台整体运行状况。

- **核心指标**：用户数、新增用户、空间数、作品数、任务量、算力消耗、收入、转化率。★
- **数据可视化**：趋势图、排行、占比等大屏展示。★

### 2. 用户管理
**目的**：管理平台用户生命周期与权限。

- **用户列表 / 详情**：查看用户资料、状态、空间、消费与创作记录。
- **状态管理**：启用 / 禁用 / 封禁用户。
- **会员与套餐管理**：为用户开通、变更会员或套餐。

### 3. 权限与组织管理 ★
**目的**：统一管理平台侧角色权限与用户侧空间组织，支撑团队协作与后台治理。

- **平台角色管理（RBAC）**：定义平台后台角色（超级管理员、运营、审核员、财务、客服等）及其权限范围。
- **权限分配**：为用户分配角色，配置菜单 / 功能 / 数据范围权限。
- **空间 / 组织管理**：查看全平台空间，掌握各空间的成员、资源与配额情况。
- **空间治理**：对违规空间进行关闭、降配额、移除成员等处置。
- **协作审计**：查看关键协作与操作记录，支撑追溯。★

### 4. 内容管理
**目的**：保障平台内容合规、有序、可运营。

- **作品审核**：AIGC 内容的合规、版权、敏感信息审核。★
- **发布审核流**：处理待审核发布作品，通过 / 驳回，驱动作品状态流转。★
- **内容上下架**：控制作品对外可见状态。
- **推荐位管理**：设置推荐、置顶、运营位。★
- **分类 / 标签管理**：维护内容分类与标签体系。★
- **举报处理**：处理用户举报，给出处置结果。★
- **评论 / 互动管理**：审核与处理评论互动。★

### 5. 计费与商业化
**目的**：管理收入侧的产品、订单与对账，支撑商业闭环。

- **套餐管理**：套餐的创建、定价、上下架。
- **会员管理**：会员档位、权益、有效期管理。
- **余额管理**：充值、退款、余额调整。
- **账单管理**：订单、明细、对账与导出。
- **计费规则配置**：按次、按量、订阅等多种计费方式。
- **空间 / 配额计费**：空间存储、成员数、算力额度的购买与计费。★

### 6. 算力与任务管理
**目的**：保障创作任务的稳定执行与算力高效利用。

- **任务并发管理**：控制并发上限，避免资源过载。
- **任务队列 / 调度 / 优先级**：任务的排队、分配与优先级控制。★
- **任务失败处理与重试**：失败任务的告警、重试与人工干预。★
- **算力资源监控与分配**：监控各类资源消耗，按需分配。★

### 7. 智能体与模型管理
**目的**：统一管理创作能力所依赖的智能体与模型资源。

- **智能体管理**：技能、生成模板、生成模型的管理。
- **模型接入管理**：视频 / 图像 / 语言模型的多厂商接入与统一管理。★
- **风格库管理**：画面风格库的维护与增删。★

### 8. 平台配置
**目的**：集中配置平台运行所需的各类参数与开关。

- **全局配置**：站点信息、功能开关、限流阈值等。★
- **合规配置**：AIGC 标识、水印、协议与条款管理。★
- **国际化 / 多语言管理**：多语言内容与文案管理。★

### 9. 运营管理 ★
**目的**：支撑平台营销与运营活动。

- **活动管理**：优惠、营销、邀请等活动配置。
- **Banner / 公告位管理**：运营位内容配置。
- **教学课程管理**：课程内容的维护。
- **数据埋点与统计报表**：运营数据的采集与报表生成。

## 五、通用 / 底层能力（两端共用）★

- **统一登录鉴权与权限控制**：身份认证与访问控制。
- **空间与权限模型底座**：支撑"空间 + 成员角色 + 权限"的协作基础能力。★
- **消息推送与通知中心**：消息的生成、分发与送达管理。
- **内容安全与合规审核**：AIGC 标识、敏感内容识别。
- **审计日志与操作记录**：关键操作的留痕与追溯。
- **文件存储与资产管理底座**：素材的统一存储与访问。
- **搜索能力**：作品、用户、素材的检索。
- **埋点数据采集与统计分析**：行为数据的采集与统计。
- **异常监控、告警与日志**：运行异常的发现与处理。
- **帮助 / 工单 / 客服支撑**：用户求助与客服闭环。

## 六、原稿未覆盖、建议补充的功能点汇总 ★

1. **空间与团队协作**：默认空间、成员邀请、角色权限、协作留痕。
2. **内容合规与审核**：AIGC 内容标识、敏感内容审核、版权声明、举报机制。
3. **内容消费互动**：评论、点赞、收藏、关注、分享、搜索、推荐。
4. **会员 / 积分 / 优惠营销**：除充值外的商业化手段。
5. **数据与运营分析**：创作数据、消费数据、运营报表、埋点。
6. **任务调度与稳定性**：任务队列、失败重试、并发控制、算力分配。
7. **权限与组织（RBAC）**：平台后台角色权限、空间治理。
8. **安全与风控**：账号安全、支付风控、异常行为告警。
9. **备份与容灾**：素材备份、任务可恢复。
10. **帮助与客服**：帮助中心、工单、客服反馈闭环。
11. **任务与接单**：任务信息发布与接单意向登记（不涉及沟通与结算，由客服线下撮合）。
