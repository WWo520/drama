# 用户端

## 1. 账号与登录

### 功能清单
- 注册、登录（手机号 / 邮箱 / 第三方 / 扫码）
- 找回 / 重置密码
- 账号安全（绑定、改密、登录设备、异地提醒）
- 游客浏览
- 空间初始化（登录自动创建默认空间）

### 功能阐述
用户通过手机号或邮箱注册并登录，登录后自动创建个人默认空间作为创作与协作的归属单位。支持第三方与扫码登录以降低门槛。未登录用户可浏览发现页，但发起创作与消费需登录。账号安全提供绑定、改密与登录设备管理，异地登录触发提醒。

---

## 2. 空间与团队协作 【重点功能】

### 功能清单
- 默认空间 / 多空间 / 空间切换
- 空间设置（名称、头像、简介、可见性）
- 空间配额（存储、成员数、算力额度）
- 成员邀请（账号 / 手机号 / 链接 / 二维码）
- 成员角色（owner / admin / member / viewer）
- 成员调整（移除、改角色、转让所有权）
- 空间内资源共享与协作权限
- 协作记录 / 审计

### 功能阐述
**空间是平台资源归属与权限控制的基本单位**，所有创作资源（项目、资产、分镜、任务、作品）都归属于某个空间。

- **默认空间**：用户注册登录后自动创建，无需手动建，保证个人即可直接创作。
- **多空间与切换**：用户可拥有或加入多个空间（个人空间 + 团队空间），随时切换当前工作空间，切换后界面与数据上下文随之更新。
- **成员与角色**：成员角色决定可执行操作——
  - `owner`：全部权限，含转让所有权；
  - `admin`：管理成员、编辑资源；
  - `member`：可创建 / 编辑 / 提交生成；
  - `viewer`：只读。
- **协作**：团队成员在空间内共享剧本、资产、分镜等资源，按角色协同推进同一项目；关键操作留痕可追溯。
- **配额**：空间的存储、成员数、算力额度受配额约束，超额可购买扩容（关联计费模块）。

> 该模块贯穿所有创作与资源操作，是权限校验（空间角色）的载体，见《系统架构》空间权限设计。

## 3. 创作中心 【核心重点】

平台核心，承载"剧本 → 分镜 → 视频"的完整生产闭环。

### 3.1 创作页 / 通用设置

**功能清单**
- 画面风格库
- 模型配置（四类模型：大语言 LLM / 文生图与图生图 T2I·I2I / 视频 T2V·I2V / 音频 audio，含模型、分辨率、比例、时长）
- 智能体技能配置

**功能阐述**
为一部剧配置全局基础参数，作为后续各环节默认值：选择画面风格基调，配置四类生成模型与画幅时长，并启用分镜脚本生成、视频任务规划、单视频提示词润色等智能体技能。模型可来自多个厂商，按能力（LLM / 文生图 / 图生图 / 视频 / 音频）区分选择。

### 3.2 剧本拆分

**功能清单**
- 叙事单元（名称、内容、状态、时长）
- 自动拆分 / 重新生成 / 排序 / 本集预设时长

**功能阐述**
把一集剧本拆为更小的可执行"叙事单元"，便于逐段生成与编排。支持自动按剧本拆分、对结果不满意重新生成、自由排序，并可设置整集目标时长辅助拆分比例。每个单元有独立状态（未开始 / 生成中 / 已完成 / 失败）。

### 3.3 资产管理

**功能清单**
- 资产概览
- 角色资产（多角色、多形象、声音）
- 场景资产（2D / 3D）
- 道具资产（2D / 3D）
- 智能镜头资产
- 通用素材（图片 / 视频 / 音频）
- 资产能力：提取描述、生成资产图、重新上传、重新生成、增删改查
- **衍生资产**（换装 / 多形态 / 虚背 / 多角度，单独或批量生成）

**功能阐述**
统一管理创作所需资源，保证角色 / 场景一致性，并**充分应用四类模型做资产生成**：
- **角色资产**：用文生图模型生成角色形象图，用**音频生成模型**生成角色声音 / 配音（多形象、多声音）。
- **场景 / 道具资产**：用文生图 / 图生图模型生成，区分 2D / 3D。
- **智能镜头资产**：为视频生成提供镜头参考，可从视频抽帧或生成参考图。
- **通用素材**：图片 / 视频 / 音频的素材库。
- **衍生资产（两级结构）**：顶层资产（角色 / 场景 / 道具）可通过 `parent_id` 自关联衍生出多个**衍生资产**（同一角色的换装、多形态、虚背、多角度等），每个衍生资产生成独立形象图；支持对单个衍生资产生成，也支持对多个衍生资产**批量生成**（如批量换装）。衍生资产与顶层资产独立命名 / 独立提示词 / 独立状态，是保证角色多形态一致性的关键。
- 每个资产记录**生成来源（模型）、参数、历史版本**；支持提取描述、按描述生成、重新上传 / 重新生成，以及完整增删改查。

### 3.4 视频制作 【重点】

**功能清单**
- 叙事单元 → 分镜脚本 → 视频的流水线
- 分镜脚本（镜头编号、时长、内容）
- 分镜图：**批量生成 / 批量删除 / 帧间插入 / 图片编辑 / 网格预览 / 网格缩放**
- 视频生成参数（分镜、关联资产、配置）
- 历史版本留存与对比
- 成片预览、合成视频、导出工程文件
- **多轨时间线编辑**（视频 / 图片 / 音频三轨，画布尺寸随比例自适应）
- **TTS 配音**（角色声音 → 配音）
- 字幕擦除、手动抽帧

**功能阐述**
核心流水线分两步：
1. **叙事单元 → 分镜脚本**：基于叙事单元生成一个或多个分镜脚本，可配置扩写剧本、生成模板与生成模型；每个分镜含镜头编号、时长、固定格式内容。
2. **分镜 + 资产 → 视频**：选择分镜脚本与关联资产，按视频配置提交生成任务，任务异步执行（见《后端方案》任务调度引擎）。

生成结果支持历史版本留存与对比，可就地预览成片、将多段视频合成完整成片、导出可复用工程文件。另有字幕擦除、手动抽帧等辅助能力。

**分镜图生产（重点）**：以帧网格形式组织分镜图，支持：
- **批量生成分镜图**（可配置并发数、强制重生成），异步任务 + 状态轮询回填；
- **帧间插入**：在任意两张分镜图之间插入新分镜（编辑图片后插入）；
- **批量选择 / 全选 / 批量删除**单帧或分镜；
- **图片编辑**：基于原图 + 参考资产图（图生图 / 多图参考）编辑分镜图；
- **网格拼图预览 / 下载 / 缩放**，便于整体检查镜头衔接。

**多轨视频合成（重点）**：视频合成基于**多轨时间线**编辑（视频 / 图片 / 音频三轨），画布尺寸随项目视频比例自适应（如 16:9 → 1920×1080、1:1 → 1080×1080、9:16 → 1080×1920），支持拖拽轨段、调整时长与层级，完成满 / 快 / 快速预览与成片导出。

### 3.5 Agent 配置

**功能清单**
- 基础参数（画面风格、视频 T2V、角色/道具/场景 T2I，多模型接入）
- 分镜脚本生成技能（模板、模型，多模板/多模型）
- 视频任务规划技能
- 单视频提示词润色技能
- **导演叙事技能库**（预设叙事手法 / 运镜 / 节奏）
- **智能体记忆管理**（会话记忆 / 摘要记忆 / 全部清除）
- **智能体思考等级**（关闭 / 轻 / 深 / 极限）
- **TTS 配音 Agent**（角色声音 → 台词配音）

**功能阐述**
让创作者配置与控制创作中使用的智能体行为：配置画面风格、各类 T2I/T2V 模型，并为三个智能体技能分别配置生成模板与生成模型，实现可复用、可调整的创作能力。此外：
- **导演叙事技能库**：提供面向导演的叙事手法技能（运镜、节奏、情绪、转场等），供智能体在分镜 / 视频规划时选用，提升成片叙事质量。
- **智能体记忆管理**：智能体可维护会话级与摘要级记忆（用于跨会话保持项目上下文），创作者可一键清除会话记忆 / 摘要记忆 / 全部记忆。
- **思考等级**：控制智能体推理深度（关闭 / 轻 / 深 / 极限），在速度与质量之间取舍。
- **TTS 配音 Agent**：为分镜 / 台词生成角色配音，复用角色声音资产，经音频生成模型产出配音轨。

### 3.6 自由画布
以无限画布形式可视化编排创作环节，灵活组合剧本、资产、分镜、视频生成等节点：
- **节点类型**：剧本、导演计划、分镜表、资产、分镜图、工作台（视频合成）等；
- **画布操作**：节点拖拽、平移、缩放、自动布局、集数切换、节点位置保持；
- **AI 对话面板**：右侧与智能体对话，AI 流式返回结构化内容并实时渲染到各节点，边生成边保存；
- 画布数据随项目持久化，支持历史回溯与并行生产。

### 3.7 剧集操作台（页面 / 接口改造）
对剧集生产与管理的操作界面进行改造，提升操作效率与一致性（原稿明确的改造需求）。

## 4. 作品与发布

### 功能清单
- 作品类型（项目 / 画布 / 视频成片）
- 作品列表 / 检索 / 草稿箱 / 回收站（恢复 / 彻底删除）
- 发布（可选）+ 审核流转
- 团队共享

### 功能阐述
统一管理创作产出。作品可选择**是否发布到平台**，发布为可选能力；一旦提交发布则进入审核流：`未发布 → 待审核 → 已发布 / 已驳回`，驳回后可修改重新提交。回收站防止误删。作品在所属空间内共享，按成员角色控制访问。该功能与管理端「内容管理」的发布审核流对接。

## 5. 任务与接单

### 功能清单
- 任务发布（标题、描述、所需能力、参考、期望周期）
- 任务状态（草稿 / 发布中 / 已截止）
- 任务广场（浏览 / 筛选 / 搜索）
- 我要接单（登记意向 + 能力简介 + 联系方式）
- 意向管理（收到的意向 / 我登记的意向）

### 功能阐述
让用户发布制作任务或承接任务。**该功能为用户个人级行为，不归属空间**；仅做信息发布与意向登记，不涉及在线沟通、合同与资金结算；双方由平台客服手动线下撮合。任务发布后进入广场供浏览，有意向者登记接单意向，发布方可查看收到的意向。

## 8. 商业与会员

### 功能清单
- 套餐购买（多版本：basic / pro / enterprise 等，支持**月付 / 年付**）与支付对接
- 积分包购买（单独购买积分）
- 积分账户（余额查询、积分流水）
- 会员订阅状态（生效 / 到期）
- 订单记录
- 创作扣费统一走积分

### 功能阐述
实现平台商业化（创作者不参与变现）。**平台无钱包/充值余额概念**，商业化围绕套餐与积分展开：
- **套餐**：提供多个版本（basic / pro / enterprise 等），每个版本支持**月付或年付**，按套餐赠送/提供周期内积分额度与相应权益（并发、存储、功能等）。
- **积分包**：用户可**单独购买积分**，不与套餐绑定。
- **统一积分扣费**：**所有创作扣费（资产图、视频、分镜等生成任务）统一按积分扣除**，按模型与参数计量积分成本（关联管理端计费模块与计费计量服务）。
- 购买套餐 / 积分包均通过订单 + 支付完成，支付成功后发放积分；提供积分余额、流水与订单查询，支持对账。

# 管理端

## 1. 平台概览（Dashboard）

**功能清单**：核心指标（用户 / 空间 / 作品 / 任务 / 算力 / 收入 / 转化率）、趋势图、排行、占比大屏。
**功能阐述**：帮助运营快速掌握平台整体运行状况，支持指标可视化与下钻。

---

## 2. 用户管理

**功能清单**：用户列表 / 详情、状态管理（启用 / 禁用 / 封禁）、会员与套餐开通。
**功能阐述**：管理用户生命周期，查看用户资料、状态、空间、消费与创作记录；支持封禁处置与会员 / 套餐开通。

---

## 3. 权限与组织管理 【重点】

**功能清单**
- 平台角色管理（RBAC：超级管理员 / 运营 / 审核员 / 财务 / 客服等）
- 权限分配（菜单 / 功能 / 数据范围）
- 空间 / 组织管理（全平台空间与成员、配额查看）
- 空间治理（关闭 / 降配额 / 移除成员）
- 协作审计

**功能阐述**
统一管理**平台侧后台角色权限**与**用户侧空间组织**：
- **平台 RBAC**：定义后台角色及其权限范围，为用户分配角色，控制管理端菜单、功能与数据范围可见性。
- **空间治理**：运营可查看全平台空间，掌握成员与配额，对违规空间进行关闭、降配额、移除成员等处置。
- **审计**：查看关键协作与操作记录，支撑追溯与合规。

---

## 4. 内容管理 【重点】

**功能清单**
- 作品审核（AIGC 合规 / 版权 / 敏感信息）
- 发布审核流（通过 / 驳回）
- 内容上下架、推荐位管理、分类 / 标签
- 举报处理、评论 / 互动管理

**功能阐述**
保障平台内容合规、有序、可运营。核心是**发布审核流**：用户提交发布（可选）→ 作品进入 `待审核` → 审核员通过（`已发布`，进入发现流）或驳回（`已驳回`，附意见，用户可改后重提）。同时处理举报与评论互动，维护分类标签与推荐位。

---

## 5. 计费与商业化 【重点】

**功能清单**
- 套餐管理（多版本创建 / 定价 / 月付与年付价格 / 上下架）
- 积分包管理（积分数量 / 定价 / 上下架）
- 会员订阅管理（订阅记录 / 有效期 / 续费 / 取消）
- 积分账户管理（积分调整 / 退款）
- 计费规则配置（各生成任务 / 模型的积分成本）
- 订单管理（明细 / 对账 / 导出）
- 空间 / 配额计费（存储 / 成员 / 算力额度，消耗积分扩容）

**功能阐述**
管理平台商业化产品、计费规则与订单对账。**无钱包/余额体系**：
- 配置多个**套餐版本**（basic / pro / enterprise 等），每个版本支持**月付 / 年付**定价；配置**积分包**供单独购买积分。
- 配置**计费规则**：各生成任务（资产图 / 视频 / 分镜等）按模型与参数对应的**积分成本**。
- 订单与积分流水可对账；积分账户支持人工调整与退款。
- 空间配额（存储、成员、算力）扩容消耗积分。
- 创作者不参与变现。

## 6. 算力与任务管理 【重点】

**功能清单**
- 任务并发管理（三级并发上限）
- 任务队列 / 调度 / 优先级
- 任务失败处理与重试、超时回收
- 算力资源监控与分配

**功能阐述**
保障生成任务稳定执行与算力高效利用。以平台内置任务调度引擎（见《后端方案》）统一管理所有异步生成任务：控制全局 / 空间 / 用户三级并发，队列按优先级调度；失败 / 超时 / 断连自动重试，超限标记失败；监控各类资源消耗并按需分配。该模块与用户端创作任务的执行、计费计量强相关。

## 7. 智能体与模型管理 【重点】

**功能清单**
- 智能体技能管理
- **导演叙事技能库管理**
- **智能体记忆管理**（会话 / 摘要记忆查看与清除）
- **智能体思考等级配置**
- 模型接入管理：四类模型（大语言 LLM / 文生图 T2I / 图生图 I2I / 视频 T2V·I2V / 音频 audio）多厂商接入
- 模型 API Key 管理：同一厂商多 Key、每 Key 独立并发限制、启用/停用
- 模型路由与并发策略：Key 负载均衡、429 切换、退避重试
- 接口限流限速配置：各接口按用户 / IP 限流
- 画面风格库

**功能阐述**
统一管理创作所依赖的智能体与模型资源：
- **四类模型接入**：按能力（LLM / 文生图 / 图生图 / 视频 / 音频）接入多个厂商，厂商区分用名称；每个厂商可配置多个模型。
- **多 Key 管理**：每个厂商可配置多个 API Key，每个 Key 有独立并发/速率限制（RPM / QPS），支持启用/停用与密钥轮换（Key 加密存储、脱敏展示）。
- **并发与路由**：调用时按「模型能力 + 可用 Key 并发 + 优先级」路由选择，多 Key 分摊额度；命中限流（429）自动切换可用 Key 或退避重试，连续失败告警。
- **接口限流**：配置各接口对用户 / IP 的限流阈值，防止滥用。
- 维护智能体技能模板、画面风格库与**导演叙事技能库**。
- **智能体记忆**：查看与清除各智能体的会话记忆 / 摘要记忆，支撑项目上下文管理与隐私合规。
- **思考等级**：配置智能体可用的思考等级（关闭 / 轻 / 深 / 极限）及默认档位。

# 重点功能展开（汇总）

以下功能是平台的关键，已在各模块展开，此处汇总其核心逻辑：

1. **空间与团队协作**：空间为资源归属与权限边界；成员分四级角色；所有资源操作过空间权限校验。
2. **创作流水线**：剧本 → 叙事单元 → 分镜脚本 → 视频，全程异步，含历史版本与资产关联。
3. **任务调度引擎**：统一异步任务模型，三级并发、优先级队列、失败重试、进度上报、计费联动。
4. **作品发布审核流**：发布可选，`未发布 → 待审核 → 已发布 / 已驳回`，用户端与管理端闭环。
5. **商业化计费**：套餐（多版本、月付/年付）+ 积分包，创作扣费统一走积分，订单对账；创作者不参与变现。
6. **任务与接单**：仅信息发布与意向登记，由客服线下撮合，无沟通与结算。
