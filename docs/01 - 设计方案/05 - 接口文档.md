## B. 全局约定（后端按这个写，不用再讨论）

### B1. 通用规范

| 项 | 约定 |
|----|------|
| **Base URL** | 生产 `https://api.example.com/v1`；开发 `http://localhost:8000/v1`；前端浏览器直连，无 BFF |
| **请求方法** | 查=GET；新建=POST；全量改=PUT；部分改=PATCH；删=DELETE |
| **Content-Type** | 一律 `application/json; charset=utf-8`（文件上传除外是 `multipart/form-data`） |
| **字符编码** | 全链路 UTF-8，接口里禁止出现 GBK/ISO-8859-1 |
| **时间格式** | 所有时间戳一律 **ISO 8601 带时区**：`2026-08-10T14:30:00+08:00`，后端存 TIMESTAMPTZ；**不用 Unix 时间戳，不用 YYYY-MM-DD HH:mm:ss 无时区** |
| **主键 ID** | 对外统一暴露 **UUID**（或 `task_uuid` / `txn_uuid`），**禁止直接暴露 BIGSERIAL 自增 id** 防遍历；内部外键仍用 BIGINT |
| **分页** | 列表接口一律 `?page=1&page_size=20`；响应体带 `pagination:{page,page_size,total,total_pages}` |
| **排序** | 列表接口一律 `?sort=created_at&sort_order=desc`；多排序 `?sort=status,updated_at&sort_order=asc,desc` |
| **软删除查询** | 列表默认不返回 deleted_at 非空数据；要查历史加 `?include_deleted=true` |
| **幂等** | 所有写接口（POST/PUT/PATCH/DELETE）请求头支持 `Idempotency-Key: <uuid>`；作用域固定为“认证主体 + HTTP 方法 + 规范化路径”。服务端必须保存至对应业务终态可查询，不得以 60 秒缓存替代任务/支付幂等；同 key 且请求摘要一致时返回首次业务资源，摘要不一致返回 409。 |
| **限流响应头** | 返回头 `X-RateLimit-Limit`（总配额）/ `X-RateLimit-Remaining`（剩余）/ `X-RateLimit-Reset`（重置时间戳）/ 超限时 `Retry-After` |
| **限流策略** | 未登录 20次/分钟；普通用户 60次/分钟；VIP1=120；VIP2=200；VIP3=300；管理端接口独立限频 |
| **部署形态** | 前端为纯静态 Vite SPA（无 BFF），浏览器直接访问 `/api/v1` 前缀，CORS/鉴权统一由后端网关层处理 |

### B2. 统一响应体包装（ApiResponse<T>）

**无论成功失败，所有 HTTP 2xx/4xx/5xx 一律套这个结构**，前端只用解析一次：

**ApiResponse\<T\> 字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| code | number | 业务错误码，0=成功，非0=见 C 节错误码字典 |
| message | string | 人类可读信息，成功="ok"，失败=用户友好提示 |
| data | T \| null | 响应载荷，失败=null |
| request_id | string | 每次请求唯一 UUID（后端注入，出问题用户甩过来能查整条链路） |
| timestamp | string | ISO8601 响应生成时间 |

**PaginationWrapper\<T\> 字段**：items（列表数据）+ pagination（page / page_size / total / total_pages）。

**示例**：成功 → `code=0, message="ok", data={project_id:"p-xxx"}`；失败 → `code=40003, message="积分余额不足，本次批量生成需200积分，当前余额150", data=null`。

> **后端注意**：Gin 中间件统一包装响应，不要在每个 Handler 里手写 `{code:0,...}`。错误码常量集中定义（dto/error_code.go）。

### B3. 鉴权方式（JWT 双 Token）

业务请求带请求头 `Authorization: Bearer <access_token_jwt>`；仅 `/auth/refresh` 和 `/auth/logout` 使用 HttpOnly Cookie `refresh_token=<refresh_token_jwt>`。

- **Access Token**：JWT，有效期 2 小时，`sub` 字段 = user_uuid
- **Refresh Token**：HttpOnly Cookie，`refresh_token=xxx; Secure; SameSite=Lax; Path=/api/v1/auth; Max-Age=604800`（7天）
- **登录流程**：POST /auth/login → 返回 access_token + 种 Cookie refresh_token
- **401 后自动刷新**：前端拿到 `code=10002` → 后台 `POST /auth/refresh`（Cookie自动带）→ 拿新 access_token 重放原请求 → refresh 也 401（code=10005）才踢登录页
- **登出**：前端删 access_token + `POST /auth/logout` 后端把 refresh_token 加 Redis 黑名单（直到过期）

### B4. 分页 / 排序 / 过滤通用参数

```yaml
components:
  parameters:
    PageQuery:
      in: query

      in: query
      name: page_size
      schema: { type: integer, default: 20, minimum: 5, maximum: 100 }
      description: 每页条数
    SortQuery:
      in: query
      name: sort
      schema: { type: string, default: created_at }
      description: 排序字段，多字段逗号分隔
    SortOrderQuery:
      in: query
```

## F. WebSocket 消息协议（服务端 10 种 + 客户端 4 种 · JSON · 心跳重连策略）

### F1. 连接路径与鉴权

连接地址 `ws(s)://api.example.com/ws/v1?token=<access_token>`，或通过 Upgrade Header `Authorization: Bearer <xxx>` 传递。

- 所有消息统一 JSON 格式，字段 `type` 必填
- 心跳：客户端每 **30秒** 发 `PING`，服务端 10秒 内回 `PONG`，否则视为断线
- 断线重连：**指数退避** `1s → 2s → 4s → 8s → 16s → 32s(上限)`，网络恢复后立刻尝试；连 10次失败弹提示
- 订阅：连接成功后客户端发 `SUBSCRIBE` 订阅自己关心的频道（如 `tasks:{task_uuid}` / `user:{user_id}`）；服务端在订阅时按认证身份校验频道归属，拒绝越权频道且只返回 `ERROR`，不得以频道存在性泄露空间、任务或成员信息。`space:{space_id}:billing` 仅允许当前 `TEAM` 空间的 OWNER/ADMIN 订阅。

### F2. 服务端→客户端 消息（10种）

所有消息均含 `type` + `ts`（ISO8601），带 channel 的按订阅频道分发：

| type | 频道 | data 字段 | 用途 |
|------|------|----------|------|
| WELCOME | — | connection_id / heartbeat_interval_ms(30000) / server_version | 连接成功欢迎包 |
| ERROR | — | code / message / ref_id（关联客户端消息 ID） | 消息格式/业务错误，连接不断开 |
| PONG | — | client_ts（回显客户端时间戳） | 心跳响应 |
| TASK_PROGRESS | tasks:{task_uuid} | task_uuid / status / progress_pct(0~100) / message / eta_seconds | 单任务进度（最常用） |
| TASK_SUCCESS | tasks:{task_uuid} | task_uuid / result{url, duration_sec, cost_points, thumb_url} | 任务完成 |
| TASK_FAILED | tasks:{task_uuid} | task_uuid / error_code / message / can_retry / retry_count_left | 任务失败 |
| TASK_CANCELLED | tasks:{task_uuid} | task_uuid / frozen_points_refunded / reason | 任务被取消 |
| BATCH_PROGRESS | batches:{batch_uuid} | batch_uuid / total / succeeded / failed / running / pending / points_deducted_so_far | 批量任务汇总进度（Step2 总进度条） |
| NOTIFY | user:{user_id} | notification_id / type / title / content / link | 通知实时推送（替代部分轮询） |
| POINTS_BALANCE_CHANGED | user:{user_id} | balance_after / delta / reason / related_txn_id | 个人积分余额变更（充值到账/扣费/退款/到期扣减），前端刷新个人余额显示 |
| SPACE_POINTS_BALANCE_CHANGED | space:{space_id}:billing | space_id / available_balance / frozen_balance / delta / reason / related_txn_id | 团队共享账户余额或冻结额变化；仅 TEAM 空间 OWNER/ADMIN 可订阅，前端只更新该空间账户与全员报表缓存 |

### F3. 客户端→服务端 消息（4种）

| type | 字段 | 用途 |
|------|------|------|
| PING | client_ts（毫秒时间戳） | 心跳，每 30 秒发一次 |
| SUBSCRIBE | channels[]（可一次订阅多个，如 `user:{id}` / `tasks:{id}` / `batches:{id}`；`space:{space_id}:billing` 仅 TEAM 空间 OWNER/ADMIN 可订阅，其他角色请求该频道返回 ERROR 10004） | 订阅频道 |
| UNSUBSCRIBE | channels[] | 取消订阅 |
| TASK_CANCEL_REQUEST | task_uuid / reason | 前端发起取消任务（WS 快速通道，HTTP 接口也保留） |
