## A. 总体策略：双应用 + Monorepo + 共享工程规范

### A1. 双前端应用架构

本项目同时建设**两个独立的 React SPA 应用**，共享一套工程规范、请求封装、组件库与工具包：

| 应用 | 包名 | 目标用户 | UI 体系 | 设计目标 |
|------|------|---------|--------|---------|
| **用户端 Web** | `apps/web-user` | 短剧创作者（C端/B端小团队） | 自建组件 + Tailwind CSS | 美观大方、影视感、突出创作体验、动效克制高质 |
| **管理端 Web** | `apps/web-admin` | 运营/管理员/审核员 | Ant Design Pro Layout | 高效清晰、表格优先、RBAC 权限细粒度控制 |

### A2. Monorepo 工程体系

- **包管理器**：pnpm workspace（比 npm/yarn workspace 更快、更省磁盘、幽灵依赖防护）
- **工程规范四件套统一**：两个应用 + 所有共享包全部引用根目录配置，禁止各自为政：
  - `tsconfig.base.json`：strict=true、noImplicitAny=强制、paths alias 统一
  - `.eslintrc.cjs`（根）+ `eslint-plugin-react-hooks` + `eslint-plugin-import` 顺序强约束
  - `.prettierrc`（根）：统一 2 空格 / 单引号 / 无分号 / 行宽 100
  - `commitlint + husky`：Conventional Commits，feat/fix/docs/chore 前缀强制，`git commit` 卡点
- **TypeScript 严格模式零容忍**：`any` 必须写 eslint-disable 注释 + 理由，`// @ts-ignore` 禁止出现在非第三方库代码里

### A3. 为什么选 SPA（Vite）而不是 Next.js SSR

| 维度 | Vite + React SPA（本次选择） | Next.js SSR |
|------|----------------------------|-------------|
| **团队学习成本** | ✅ 团队已有 React + 路由 + 状态管理基础，无需学习 RSC/Server Actions | ❌ 要学 App Router 约定、RSC 和 Client 组件边界、Server Actions |
| **首屏 SEO 重要性** | ✅ 短剧创作平台首屏是用户登录后的工作台，搜索引擎爬虫不登录抓不到，SSR 收益为 0 | ❌ 多花 SSR 服务器运维成本，无实际 SEO 收益 |
| **部署复杂度** | ✅ 纯静态文件，丢 CDN（阿里云 OSS / 七牛 / Cloudflare）就完事，无 Node 服务器 | ❌ 需要常驻 Node 进程，运维要处理内存泄漏、PM2 进程守护、冷启动 |
| **开发体验** | ✅ Vite HMR 100ms 级热更新，修改立即生效 | ⚠️ Next.js App Router HMR 常触发整页刷新，RSC 调试慢 |
| **与后端 API 对接** | ✅ 直接 axios 调后端，BFF 层可后期加 nginx 反向代理实现 | ❌ 多一层 Route Handlers，多一次网络跳转增加延迟 |
| **未来可扩展性** | ✅ 如果哪天要做首页营销页 SEO，单独再加一个 Next.js 官网站即可 | — |

> **结论**：短剧创作平台是「登录后使用的生产力工具」，非「公开内容站点」，Vite SPA 是性价比最优解。

## D. 🔴 状态分层黄金公式（重点 · 对齐 11 号 A 节换栈）

> **黄金公式**：`① 能放 React Router useSearchParams 的，不放 Zustand；② 能放 TanStack Query Cache 的，不放 Zustand；③ 剩下（操作频繁 UI 态/跨组件共享）才放 Zustand。`
>
> **铁律**：Zustand 单个 Store ≤ 10 字段，全部 Store 总字段 ≤ 60。超过了就要自查"这个能不能放回 URL / TanStack Query"。

### D1. 四层状态分层详解

| 分层 | 存储位置 | 典型内容 | 示例 |
|------|---------|---------|------|
| **L1 持久 URL（最推荐）** | React Router `useSearchParams()` → `?xxx=yyy` | 分页(page/page_size)、排序(sort/order)、筛选(status/keyword)、当前Step、当前集、当前选中的资产id/镜头id、弹窗是否打开（分享链接可复用） | `/workspace/project/p-xxx?episodeId=e-xxx&step=2&selected_asset_ids=cv-aaa,cv-bbb` |
| **L2 TanStack Query Cache（次推荐）** | `queryClient.getQueryData(['GET:/api/v1/projects', {page:1}])` | 所有 GET 请求返回值（项目列表/资产详情/任务状态）→ TanStack Query 统一管 dedupe + 缓存 + 重验证 + 垃圾回收 | `useQuery({ queryKey: ['GET:/api/v1/projects', {page:1}], queryFn })` |
| **L3 页面内本地 state（第三推荐）** | React `useState`（组件内） | 临时 UI：输入框值、是否 hover、单个卡片展开/折叠、input focus | `const [scriptText, setScriptText] = useState('')` |
| **L4 Zustand 全局（最后选择！别什么都塞）** | Zustand store + persist (localStorage 仅存必要) | ①用户登录态（access_token + user info）②工作台四步共享：资产勾选集合/临时草稿③WebSocket连接状态④跨页面临时操作态（批量任务已选id跳转Step3还能看到）⑤充值弹窗/侧边栏折叠等纯UI态 | `useAuthStore(s => s.accessToken)` → 存 localStorage |

### D2. L1 为什么优先放 URL（useSearchParams 是真源）

```
✅ 好的做法（URL 是真源）：
/workspace/project/p-123?episodeId=e-456&step=2
→ 分享链接给朋友点进来：直接进 Step2 看资产（要登录+权限）
→ 浏览器后退：回到 Step1
→ 刷新页面：step 不变
→ Ctrl+Shift+T 误关标签恢复：状态全还原

❌ 错误做法：
Zustand 里存 currentStep = 2
→ 刷新 = 重置 Step1
→ 分享链接 = 朋友从 Step1 开始
→ 后退 = 退到 /projects（不是 Step1）
→ 误关标签 = 全丢
```

> **扩展原则**：所有「希望分享链接能复现」的东西，一律塞 Search Params。Step、选中资产ID、镜头ID、打开的弹窗、筛选排序——全放 URL。参数多没关系，React Router 性能没问题。

### D3. SearchParams 命名约定（全项目统一，避免混用）

| 约定键名 | 类型 | 示例 | 用途 |
|---------|------|------|------|
| `step` | enum `1\|2\|3\|4` | `?step=2` | 当前工作台 Step |
| `projectId` | uuid | `?projectId=p-uuid4` | 兜底（路径里也有，但参数里写一份方便组件直接取） |
| `episode` | number | `?episode=1` | 当前集序号（M0单集写死=1，M1多集有用） |
| `narrativeUnitId` | uuid | `?narrativeUnitId=b-uuid4` | 当前高亮/展开的叙事单元 |
| `nodeId` | uuid | `/canvas/p-xxx?nodeId=nd-uuid4` | 自由画布当前选中节点 |
| `selected_asset_ids` | `逗号分隔uuid列表` | `?selected_asset_ids=cv-aaa,cv-bbb,sc-ccc` | Step2已勾选的资产id列表（用户勾选后，切页回来还在）≤20项同步URL |
| `modal` | string enum | `?modal=batch_assets_preview` / `?modal=alipay_qr&order_no=xxx` | 当前打开的弹窗名（分享/回退时可恢复） |
| `page` / `page_size` / `keyword` / `status` | — | 同 10 号接口 | 列表页用 |
| `redirect` | encodeURIComponent | `/login?redirect=%2Fworkspace%2Fproject%2Fp-xxx` | 登录成功后跳回原页 |

### D4. 哪些东西严禁放 Zustand（放 L1/L2）

| 常被塞错的内容 | 应该放哪里 | 为什么 |
|--------------|-----------|-------|
| 项目列表 `/projects` 返回值 | TanStack Query: `useQuery(['GET:/api/v1/projects', {page:1}])` | 有分页/筛选，TanStack Query 自动 dedupe/cache/revalidate |
| 资产列表 Step2 角色/场景/道具 | TanStack Query: `useQuery(['GET:/api/v1/episodes/e-xxx/characters'])` | 重新生成后 `invalidateQueries` 自动刷新，不需要手动更新 Store |
| 积分余额 | `['GET:/api/v1/points/account']` 或 `['GET:/api/v1/auth/me'].data.points_account` | 余额变动会推 WS → 自动 setQueryData，双源不同步会出现"顶栏余额500但批量生成说不够"致命Bug |
| 任务状态 `/tasks/t-uuid` | `useQuery(['GET:/api/v1/tasks/t-uuid'])` + WS 到达时 setQueryData | 轮询降级 + 实时推送双通道 |
| 风格库列表 | `useQuery(['GET:/api/v1/styles/library'])` | 基本不变，staleTime=1h 完美 |
| 当前 step / 当前集 / 当前叙事单元 | URL SearchParams `useSearchParams()` | 分享/刷新/后退都还原，唯一真源 |

### E3. 路由 loader 守卫伪代码（看一眼就懂）

```tsx
// apps/web-user/src/router/loaders.ts
import { redirect } from 'react-router-dom'
import { useAuthStore } from '@/stores/auth.store'
import { queryClient } from '@/providers/QueryClient'
import { queryKeyProjectsDetail } from '@/hooks/useProjectDetail'
import { toast } from 'sonner'

/**
 * T1 公开路由 loader：已登录访问 /login → 跳 /projects
 */
export async function publicLoader({ request }) {
  const { isInitialized, user, ensureInitialized } = useAuthStore.getState()
  if (!isInitialized) await ensureInitialized()
  if (user) {
    const url = new URL(request.url)
    const redirectTo = url.searchParams.get('redirect') ?? '/projects'
    return redirect(redirectTo)
  }
  return null
}

/**
 * T2 受保护路由 loader：未登录 → 跳 /login?redirect=xxx
 * 每一个需要登录的路由，loader 都调这个
 */
export async function protectedLoader({ request }) {
  const { isInitialized, user, ensureInitialized } = useAuthStore.getState()
  if (!isInitialized) await ensureInitialized() // localStorage → 校验 token 有效性
  if (!user) {
    const path = new URL(request.url).pathname + new URL(request.url).search
    return redirect(`/login?redirect=${encodeURIComponent(path)}`)
  }
  // ✅ 已登录，返回当前 user 给 route useLoaderData() 直接用
  return { user }
}

/**
 * T3 工作台项目路由 loader：鉴权 + owner 校验 + 进度守卫（step 跳转）
 */
export async function workspaceProjectLoader({ params, request }) {
  // 1. 先跑通用鉴权
  const authResult = await protectedLoader({ request })
  if (authResult instanceof Response) return authResult // redirect 响应直接透传
  const { user } = authResult

  // 2. 预取项目详情（TanStack Query 缓存，页面组件 useQuery 直接命中 0 等待）
  const projectId = params.projectId
  try {
    const project = await queryClient.fetchQuery({
      queryKey: queryKeyProjectsDetail(projectId),
      queryFn: defaultQueryFn,
      staleTime: 30_000,
    })

    // 3. 越权拦截：不是 owner（M0 无团队，必须 owner_user_id = user.user_id）
    if (project.owner_user_id !== user.user_id) {
      toast.error('项目不存在或无权限访问（code=2001）')
      return redirect('/projects')
    }

    // 4. 进度顺序校验：用户手动改 URL step=4 但 step3 未完成 → 自动跳回已完成 step
    const url = new URL(request.url)
    const stepParam = Number(url.searchParams.get('step') ?? 1)
    const maxCompletedStep = project.episodes?.[0]?.current_step_num ?? 1
    if (stepParam > maxCompletedStep + 1) {
      toast.warning(`请先完成 Step${maxCompletedStep} 后再进入下一步`)
      url.searchParams.set('step', String(Math.min(stepParam, maxCompletedStep + 1)))
      return redirect(url.pathname + url.search)
    }

    // 5. ✅ 全部通过，返回给页面用
    return { user, project }
  } catch (err) {
    if (err.bizCode === 4004) {
      toast.error('项目不存在或已删除')
      return redirect('/projects')
    }
    throw err // 其他错误走 React Router errorElement
  }
}
```

### F1. useAuthStore（auth.store.ts · 唯一 persist localStorage）

```ts
/**
 * 🔐 鉴权 Store（所有页先依赖它）
 * persist localStorage：accessToken, user 信息（refreshToken 是后端 HttpOnly Cookie，前端不存）
 * 清除条件：401 code=1003 或 /auth/logout 成功 或 页面手动退出
 */
import { create } from 'zustand'
import { persist, devtools } from 'zustand/middleware'
import type { UserMeDTO, ResAuthLogin } from '@duanju/api-client'
import { apiAuth } from '@/lib/axios'

type AuthState = {
  // === State（8 个字段，≤10 ✅） ===
  accessToken: string | null
  user: UserMeDTO | null
  isInitialized: boolean       // 页面刚打开时是否已尝试过 validate token
  loginLoading: boolean
  registerLoading: boolean
  refreshTokenLock: boolean    // 防并发 refresh 死循环

  // === Actions ===
  onLoginSuccess: (res: ResAuthLogin['data']) => void          // 登录后一次填 store
  setAccessToken: (token: string) => void                      // refresh 成功只更新 token
  setUser: (user: UserMeDTO) => void                           // 充值后余额变化调这个
  logout: (reason?: 'token_expired' | 'manual' | '401') => void // 清 store + 跳转 login
  ensureInitialized: () => Promise<void>                       // 每个 loader 开头 await
}

export const useAuthStore = create<AuthState>()(
  devtools(
    persist(
      (set, get) => ({
        accessToken: null,
        user: null,
        isInitialized: false,
        loginLoading: false,
        registerLoading: false,
        refreshTokenLock: false,

        onLoginSuccess: ({ access_token, user }) =>
          set({ accessToken: access_token, user, isInitialized: true }),

        setAccessToken: (token) => set({ accessToken: token }),

        setUser: (user) => set({ user }),

        logout: (reason = 'manual') => {
          set({ accessToken: null, user: null, isInitialized: true })
          // 携带 redirect 参数，登录后跳回当前页
          const redirect = encodeURIComponent(window.location.pathname + window.location.search)
          window.location.href = reason === 'token_expired'
            ? `/login?reason=expired&redirect=${redirect}`
            : `/login?redirect=${redirect}`
        },

        ensureInitialized: async () => {
          if (get().isInitialized) return
          const token = get().accessToken
          if (!token) { set({ isInitialized: true }); return }
          try {
            const me = await apiAuth.authMe() // GET /auth/me 校验 token 有效性
            set({ user: me.data, isInitialized: true })
          } catch (e) {
            get().logout('token_expired') // token 无效直接踢
          }
        },
      }),
      {
        name: 'duanju-auth-store-v1', // localStorage key，结构不兼容改 v2
        partialize: (s) => ({
          accessToken: s.accessToken,
          user: s.user,
        }), // 只持久化这两个字段，loading/lock 等不存
      }
    ),
    { name: 'AuthStore', enabled: import.meta.env.DEV }
  )
)
```

### F3. useWebSocketStore（websocket.store.ts · 单例连接管理）

```ts
/**
 * 📡 WebSocket 全局 1 个物理 TCP 连接（不是每开 1 个 project 新开！）
 * 靠订阅 SUBSCRIBE 消息逻辑隔离（task_uuid / room_id）
 * UI 组件不直接操作 WebSocket，只调 actions。内部封装指数退避重连。
 */
import { create } from 'zustand'
import { devtools } from 'zustand/middleware'
import { WsClient } from '@/lib/ws-client' // 单例 class，见下文

type ConnStatus = 'DISCONNECTED' | 'CONNECTING' | 'ONLINE' | 'RECONNECTING' | 'DEAD'

type WsState = {
  connStatus: ConnStatus
  lastPingLatencyMs: number     // > 500ms 提示网络慢
  disconnectCount: number       // 断线次数，用于 UI 告警
  topics: Set<string>           // 当前订阅的主题列表（task:t-xxx / room:batch-xxx）

  ensureConnected: () => void                            // 登录成功后立刻调
  subscribe: (topic: string, handler: (msg: unknown) => void) => void   // 订阅单主题
  unsubscribe: (topic: string) => void
  hardDisconnect: () => void                             // 登出 / 断网时调
}

export const useWebSocketStore = create<WsState>()(
  devtools(
    (set, get) => ({
      connStatus: 'DISCONNECTED',
      lastPingLatencyMs: 0,
      disconnectCount: 0,
      topics: new Set(),

      ensureConnected: () => {
        WsClient.getInstance().connect()
        WsClient.getInstance().on('status', (s: ConnStatus) => set({ connStatus: s }))
        WsClient.getInstance().on('ping', (latency: number) => set({ lastPingLatencyMs: latency }))
        WsClient.getInstance().on('disconnect', () => set(s => ({ disconnectCount: s.disconnectCount + 1 })))
      },

      subscribe: (topic, handler) => {
        set(s => {
          const next = new Set(s.topics); next.add(topic); return { topics: next }
        })
        WsClient.getInstance().subscribe(topic, handler)
      },

      unsubscribe: (topic) => {
        set(s => {
          const next = new Set(s.topics); next.delete(topic); return { topics: next }
        })
        WsClient.getInstance().unsubscribe(topic)
      },

      hardDisconnect: () => {
        WsClient.getInstance().close()
        set({ connStatus: 'DISCONNECTED', topics: new Set() })
      },
    }),
    { name: 'WebSocketStore', enabled: import.meta.env.DEV }
  )
)

// ============================================================
// WsClient 单例类（lib/ws-client.ts · 伪代码）
// 指数退避重连：1s → 2s → 4s → 8s → 最大 60s
// ============================================================
export class WsClient {
  private static _inst: WsClient
  static getInstance() { return this._inst ??= new WsClient() }

  private ws: WebSocket | null = null
  private reconnectTimer: number | null = null
  private reconnectAttempt = 0
  private handlers: Record<string, Set<(msg: unknown) => void>> = {}
  private statusHandlers: Set<(s: ConnStatus) => void> = new Set()
  private heartbeatTimer: number | null = null

  connect() {
    if (this.ws?.readyState === WebSocket.OPEN) return
    const token = useAuthStore.getState().accessToken
    const url = `${import.meta.env.VITE_WS_URL}/ws?token=${token}`
    this.ws = new WebSocket(url)
    this.emit('status', 'CONNECTING')

    this.ws.onopen = () => {
      this.reconnectAttempt = 0
      this.emit('status', 'ONLINE')
      this.resubscribeAll()
      this.startHeartbeat()
    }
    this.ws.onmessage = (ev) => this.dispatchMessage(JSON.parse(ev.data))
    this.ws.onclose = () => {
      this.emit('status', this.reconnectAttempt > 0 ? 'RECONNECTING' : 'DISCONNECTED')
      this.emit('disconnect')
      this.scheduleReconnect()
    }
    this.ws.onerror = () => this.ws?.close()
  }

  private scheduleReconnect() {
    if (this.reconnectAttempt >= 20) { this.emit('status', 'DEAD'); return }
    const delay = Math.min(1000 * Math.pow(2, this.reconnectAttempt), 60_000)
    this.reconnectAttempt++
    this.reconnectTimer = window.setTimeout(() => this.connect(), delay)
  }

  subscribe(topic: string, handler: (msg: unknown) => void) {
    (this.handlers[topic] ??= new Set()).add(handler)
    if (this.ws?.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify({ type: 'SUBSCRIBE', topic }))
    }
  }

  unsubscribe(topic: string) { /* 移除 handler + 发送 UNSUBSCRIBE */ }
  private dispatchMessage(msg: { type: string; topic: string; data: unknown }) {
    // WS 消息 throttle 250ms 合并：同 topic 连续消息 setState 合并
    // ⚠️ 不要把消息数据塞 Zustand（消息量太大），直接调 handler → handler 内部 setQueryData
    this.handlers[msg.topic]?.forEach(h => h(msg.data))
  }
  private emit(event: string, data?: unknown) { /* 触发事件总线 */ }
  private resubscribeAll() { /* 重连后重新订阅所有 topics */ }
  private startHeartbeat() { /* 30s 发 PING，测量 PONG 延迟 */ }
  close() { /* 物理关闭 + 清定时器 */ }
}
```

### G2. 全局 queryFn 封装（统一解包 ApiResponse + BizError 抛出）

```ts
// apps/web-user/src/lib/query-fn.ts
import type { QueryFunctionContext } from '@tanstack/react-query'
import { axios } from '@/lib/axios'
import { BizError } from '@/lib/errors'

/**
 * TanStack Query 全局 queryFn
 * QueryKey = ['METHOD:/api/v1/xxx', params?]
 * 解包 10 号文档约定的 ApiResponse：{code, message, data, request_id}
 * code !== 0 → throw BizError，TanStack Query 走 isError 分支 + 全局错误 Toast
 */
export async function defaultQueryFn<TData = unknown>({
  queryKey,
}: QueryFunctionContext): Promise<TData> {
  const [methodPath, params = undefined] = queryKey as [string, Record<string, unknown> | undefined]
  const [method, path] = methodPath.split(':') as ['GET' | 'POST' | 'PUT' | 'PATCH' | 'DELETE', string]

  const { data } = await axios.request<{ code: number; message: string; data: TData; request_id: string }>({
    method,
    url: path,
    params: method === 'GET' ? params : undefined,
    data: method !== 'GET' ? params : undefined,
  })

  if (data.code !== 0) {
    const err = new BizError(data.code, data.message || '未知错误', data.request_id)
    // 业务错误：code=1xxx 参数 / 2xxx 权限 / 3xxx 积分不足 / 4xxx 资源不存在
    if (import.meta.env.DEV) console.error(`[BizError] ${data.code}: ${data.message} (req=${data.request_id})`)
    throw err
  }
  return data.data as TData
}
```

### G4. 失效（invalidateQueries + setQueryData）策略

> **核心原则**：写操作（POST/PATCH/DELETE）成功后，改了什么数据，就 invalidate 父级列表 + setQueryData 自己详情（乐观更新）。

| 写操作（接口） | 成功后执行的 TanStack Query 操作 |
|---------------|-------------------------------|
| POST `/projects` 创建项目 | ✅ `invalidateQueries({ queryKey: QK.projects_list })`（列表加新的）<br>✅ `setQueryData(QK.auth_me, prev => ({...prev, stats: ...}))`（创建数+1） |
| DELETE `/projects/p-xxx` | ✅ `invalidateQueries({ queryKey: QK.projects_list })` |
| PATCH `/characters/c-xxx` 修改角色 | ✅ `invalidateQueries({ queryKey: QK.assets_chars(eid) })`（刷新角色列表） |
| POST `/assets/batch-generate` 批量生成资产 | ❌ **不用 invalidate！** 任务异步，等 WS 推每个子任务 SUCCESS 时单独 invalidate 该资产卡片 key（不要等全批量完才刷新，体验差） |

> 场景：点击批量生成后，后端返回 202 Accepted，但积分要等 WS 或轮询才扣。为了避免用户"点完按钮余额没变还显示500"疑惑，**乐观先扣 frozen_balance UI 显示**。

```ts

const batchGenMutation = useMutation({
  mutationFn: (payload) => apiAssets.assetsBatchGenerate(payload),

  // 🔴 onMutate：提交前就改 UI（乐观更新）
  async onMutate(payload) {

    const prev = queryClient.getQueryData(QK.points_account)
    const netToFreeze = payload.preview.net_points_cost

    queryClient.setQueryData<PointsAccount>(QK.points_account, (old) => {
      if (!old) return old
      return {
        ...old,
        current_balance: old.current_balance - netToFreeze,
        frozen_balance: old.frozen_balance + netToFreeze,
      }
    })

    return { rollback: () => queryClient.setQueryData(QK.points_account, prev) }
  },

  // 失败：回滚乐观更新
  onError(_err, _vars, ctx) {
    ctx?.rollback?.()
    toast.error('提交失败，积分已返还')
  },

  // 成功：精确 invalidate，从后端拉最新真源数据覆盖
  onSuccess() {
    queryClient.invalidateQueries({ queryKey: QK.points_account })
  },
})
```

```ts
import { useQuery } from '@tanstack/react-query'
import { QK } from './query-keys'
import { defaultQueryFn } from '@/lib/query-fn'
import { useWS } from './useWS'
import { queryClient } from '@/providers/QueryClient'

/**
 * 任务进度 Hook：WS 实时推送优先，WS 断线降级轮询 3s
 * 自动在 status=SUCCESS / FAIL 时停止轮询
 */
export function useTask(taskId: string | null) {
  const q = useQuery({
    queryKey: QK.tasks_detail(taskId ?? ''),
    queryFn: defaultQueryFn,
    enabled: !!taskId,
    refetchInterval: (data) => {
      if (!data) return 3000
      // 完成 / 失败：停止轮询
      if (['SUCCESS', 'FAILED', 'CANCELLED'].includes(data.status)) return false
      return 3000
    },
    staleTime: 0, // 进度实时变化，不缓存
  })

  // WS 订阅：同 taskId 的消息直接 setQueryData，零延迟
  useWS(`task:${taskId}`, (msg: TaskProgressMsg) => {
    if (!taskId) return
    queryClient.setQueryData(QK.tasks_detail(taskId), (prev) => prev ? { ...prev, ...msg } : msg)
  })

  return {
    task: q.data,
    isLoading: q.isLoading,
    isFinished: ['SUCCESS', 'FAILED', 'CANCELLED'].includes(q.data?.status ?? ''),
    progressPercent: q.data?.progress_percent ?? 0,
  }
}
```

### I1. Axios 请求/响应拦截器伪代码（关键）

```ts
// apps/web-user/src/lib/axios.ts
import axios from 'axios'
import { toast } from 'sonner'
import { BizError } from './errors'
import { useAuthStore } from '@/stores/auth.store'
import { queryClient } from '@/providers/QueryClient'
import { QK } from '@/hooks/query-keys'

// ================ 创建实例 ================
export const axiosInstance = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL, // '/api/v1' + nginx 反代后端
  timeout: 30_000,
  headers: { 'Content-Type': 'application/json' },
})

// ================ 请求拦截：注入 token + request_id ================
axiosInstance.interceptors.request.use(config => {
  // ✅ getState() 不进入 React 渲染循环，拦截器里正确用法
  const token = useAuthStore.getState().accessToken
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  // X-Request-Id 链路追踪，出问题给用户复制粘贴
  config.headers['X-Request-Id'] = `req-${crypto.randomUUID()}`
  return config
})

// ================ 响应拦截：解包 ApiResponse + 401 refresh 重放（≤1 次防死循环） ================
axiosInstance.interceptors.response.use(
  // ========= 2xx 正常响应 =========
  (response) => {
    const data = response.data
    // code = 0：业务成功，直接返回
    if (data?.code === 0) return response
    // code !== 0：业务错误（参数错误/权限不足/积分不够等）
    if (import.meta.env.DEV) {
      console.warn(`[Biz ${data?.code}] ${data?.message} | req=${data?.request_id}`)
    }
    // 积分不足 3001 弹充值引导；权限不足 2xxx Toast
    if (![3001].includes(data?.code)) {
      toast.error(data?.message || '操作失败')
    }
    return Promise.reject(new BizError(data?.code ?? 9999, data?.message || '未知错误', data?.request_id))
  },

  // ========= HTTP 错误（非 2xx） =========
  async (error) => {
    const { config, response } = error
    const status = response?.status

    // 401 Unauthorized：token 过期 → 尝试 refresh 并重放原请求
    if (status === 401 && config && !config.__retry) {
      const auth = useAuthStore.getState()
      // 防并发 refresh：已有 refresh 在进行中，等它完成
      if (auth.refreshTokenLock) {
        return new Promise((resolve) => {
          const timer = setInterval(() => {
            const latestAuth = useAuthStore.getState()
            if (!latestAuth.refreshTokenLock) {
              clearInterval(timer)
              config.headers.Authorization = `Bearer ${latestAuth.accessToken}`
              resolve(axiosInstance(config))
            }
          }, 100)
        })
      }

      try {
        useAuthStore.setState({ refreshTokenLock: true })
        // 调 POST /auth/refresh（后端从 HttpOnly Cookie 读 refresh_token）
        const { data } = await axios.post(
          `${import.meta.env.VITE_API_BASE_URL}/auth/refresh`,
          {},
          { withCredentials: true } // 必须带 Cookie
        )
        if (data.code === 0) {
          useAuthStore.getState().setAccessToken(data.data.access_token)
          // 标记重放过，防死循环
          config.__retry = true
          config.headers.Authorization = `Bearer ${data.data.access_token}`
          return axiosInstance(config) // 重放原请求 1 次
        }
        throw new Error('refresh failed')
      } catch {
        // refresh 也 401 = 踢登录
        useAuthStore.getState().logout('token_expired')
      } finally {
        useAuthStore.setState({ refreshTokenLock: false })
      }
    }

    // 403 Forbidden：权限不足
    if (status === 403) {
      toast.error('无权限执行此操作（code=2000）')
      return Promise.reject(new BizError(2000, '无权限', response?.data?.request_id))
    }
    // 429 Too Many Requests：限流
    if (status === 429) {
      toast.error('操作过于频繁，请稍后再试')
      return Promise.reject(new BizError(4290, '请求过于频繁', response?.data?.request_id))
    }
    // 5xx 服务器错误
    if (status >= 500) {
      toast.error(`服务器错误（${status}），已通知技术团队`)
      return Promise.reject(new BizError(5000, `服务器错误 ${status}`, response?.data?.request_id))
    }
    // 网络超时 / 断网
    if (!status) {
      toast.error('网络连接失败，请检查网络')
    }
    return Promise.reject(error)
  }
)

export default axiosInstance
```

```tsx
import { useEffect } from 'react'
import { useTasksBatchStore } from '@/stores/tasks-batch.store'

export default function WorkspaceLayout({ children }) {
  const activeBatchCount = useTasksBatchStore(s => s.getActiveBatchCount())

  useEffect(() => {
    function onBeforeUnload(e: BeforeUnloadEvent) {
      if (activeBatchCount > 0) {
        e.preventDefault()
        e.returnValue = '当前有进行中的批量生成任务，离开页面后任务会在后台继续，但进度无法实时查看。确定离开吗？'
        return e.returnValue
      }
    }
    window.addEventListener('beforeunload', onBeforeUnload)
    return () => window.removeEventListener('beforeunload', onBeforeUnload)
  }, [activeBatchCount])

  return <>{children}</>
}
```

```ts
// web-admin/src/router/guards.ts RBAC loader
export async function adminRbacLoader({ request }) {
  const authResult = await protectedLoader({ request })
  if (authResult instanceof Response) return authResult
  const { user } = authResult
  if (user.role !== 'ADMIN' && user.role !== 'SUPER_ADMIN') {
    toast.error('无管理后台权限')
    return redirect('/403')
  }

  return { user, permissions: user.permissions ?? [] }
}
```
