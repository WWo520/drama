# 短剧平台接口文档

> 基于《短剧平台初步方案》《系统架构》《数据模型》
> 约定：RESTful，JSON 传输，统一返回结构，JWT 鉴权。

---

## 一、通用约定

### 1.1 鉴权
- 用户在 `Authorization: Bearer <token>` 携带 JWT。
- 管理端接口带平台角色权限校验（RBAC）。
- 空间资源接口带空间成员角色校验。

### 1.2 统一返回结构
```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```
- `code=0` 成功；非 0 为错误码（见错误码表）。
- 列表 `data`：`{ "list": [], "total": 0, "page": 1, "page_size": 20 }`。

### 1.3 分页
- 通用查询参数：`page`（默认 1）、`page_size`（默认 20，上限 100）。

### 1.4 错误码（示意）
| code | 说明 |
|------|------|
| 0 | 成功 |
| 40001 | 参数错误 |
| 40101 | 未登录 / token 失效 |
| 40301 | 无权限 |
| 40401 | 资源不存在 |
| 40901 | 状态冲突（如重复提交） |
| 42901 | 频率限制 |
| 50001 | 服务内部错误 |
| 47001 | 积分不足 |

- 前端通过预签名 URL 直传 S3（避免经后端中转）。
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/v1/uploads/presign | 申请上传预签名 URL |
| POST | /api/v1/uploads/complete | 上传完成回执（关联业务对象） |

```json
POST /api/v1/uploads/presign
{ "biz_type": "asset", "biz_ref": "...", "file_name": "a.png", "content_type": "image/png", "size": 1024 }
→ { "upload_url": "https://...", "object_key": "...", "download_url": "..." }
```

## 五、任务状态与进度（统一异步）

所有生成类接口提交后返回 `task_id`，统一用下列方式查询：
- `GET /api/v1/tasks/{id}` 轮询状态/进度。
- 状态：`queued / running / succeeded / failed / cancelled / expired`。
- 成功结果含 S3 预签名 URL。

```json
GET /api/v1/tasks/{id}
→ {
  "id": "...",
  "status": "running",
  "progress": 45,
  "result": { "url": "https://..." }
}
```

## 六、请求示例（关键接口）

**创建空间**
```json
POST /api/v1/spaces
{ "name": "我的工作室", "type": "team" }
→ { "id": "...", "name": "我的工作室" }
```

**提交视频生成任务**（`model_key` 为模型名称，即数据模型 `models.name`）
```json
POST /api/v1/storyboards/{id}/video
{ "params": { "model_key": "video-01", "resolution": "1080p", "ratio": "16:9", "duration": 10 } }
→ { "task_id": "..." }
```

**提交作品发布（可选，进入审核）**
```json
POST /api/v1/works/{id}/publish
→ { "publish_status": "pending" }
```

**管理端审核作品**
```json
POST /api/admin/works/{id}/audit
{ "action": "approve" }  // 或 reject + note
→ { "publish_status": "published" }
```
