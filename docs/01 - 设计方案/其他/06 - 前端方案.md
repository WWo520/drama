# 短剧平台前端方案

> 基于《短剧平台初步方案》《接口文档》
> 技术栈：React ｜ 管理端 Ant Design ｜ 用户端自定义美观设计

---

## 一、总体策略

- **两个前端应用**，共享一套工程规范与请求封装：
  - **用户端 Web**（`web-user`）：面向创作者，自定义设计，追求美观大方的视觉体验，突出"创作 + 消费"。
  - **管理端 Web**（`web-admin`）：面向运营/管理员，基于 Ant Design 中后台组件，重效率与清晰。
- 采用 **TypeScript**，Vite 构建，React Router 路由，状态管理用 Zustand/Redux Toolkit。
- 复用设计系统：设计变量（颜色、字体、间距、圆角）、组件库（管理端 AntD；用户端自建轻量组件）。

## 四、用户端设计要点（美观大方）

### 4.1 视觉设计原则
- 建立统一的**设计系统**：主色、辅助色、字体层级、间距栅格、圆角、阴影、动效节奏。
- 深色调 + 高质感动效的影视感风格，突出"短剧/创作"的调性；或根据品牌定浅色优雅风。
- 图像优先：封面、分镜预览、角色形象大图展示，弱化信息密度。
- 动效克制且一致：转场、加载、任务进度动画；组件动画结束后复位，不干扰焦点。

### 4.2 核心页面体验
- **创作中心**：多步骤工作台（通用设置 → 剧本拆分 → 资产管理 → 视频制作），左侧步骤导航 + 右侧内容区；任务进度可视化（进度条/卡片状态）。
- **自由画布**（核心）：以无限画布组织剧本 / 导演计划 / 分镜表 / 资产 / 分镜图 / 工作台节点，见 4.4。
- **发现/信息流**：沉浸式视频流，卡片化作品展示，一键播放/点赞/收藏。
- **空间与协作**：空间切换器清晰，成员管理直观。
- **反馈即时性**：提交任务、生成、扣费（积分）、订阅购买均有即时反馈；积分不足/额度不足给出明确提示。
- **按钮一致性**：同层级按钮尺寸、高度、风格统一（符合既有 UI 偏好）。
- **偏好设置**：个人中心提供界面主题（亮色/暗色）、多语言切换、智能体思考等级等选项。

### 4.3 交互
- 异步任务统一处理：提交返回 task_id → TanStack Query 轮询进度 → 完成展示结果；失败给出重试。
- 操作提示按需展示，不常驻。
- 响应式：桌面优先，兼顾平板/窄屏。

### 4.4 自由画布交互（导演台）
- **技术**：采用 React Flow（`@xyflow/react`）实现类无限画布，配合 Pinia/Zustand 维护画布状态、socket.io 建立与智能体的 AI 对话长连接。
- **节点类型**：剧本（script）、导演计划（scriptPlan）、分镜表（storyboardTable）、资产（assets，含顶层 + 衍生两级）、分镜图（storyboard）、工作台（workbench / 多轨视频合成）。
- **画布能力**：节点拖拽、平移、缩放（0.1~10）、空格 + 左键拖画布、自动布局、集数切换、节点位置保持（防止数据刷新回跳）；拖拽/平移期间降低渲染复杂度保证流畅。
- **AI 对话面板**：画布右侧面板与智能体对话，AI 流式返回结构化内容（XML 标签包裹）实时渲染到各节点，标签完成节流持久化（边生成边保存）；提供清除会话 / 摘要记忆、思考等级切换。
- **分镜帧操作**：帧网格展示，支持批量选择 / 全选 / 批量删除、帧间插入、图片编辑（原图 + 参考资产图）、网格拼图预览 / 下载 / 缩放。
- **工作台**：多轨时间线（视频 / 图片 / 音频三轨）视频合成编辑，画布尺寸随项目比例自适应（16:9 / 1:1 / 9:16）。

## 五、管理端设计要点（Ant Design）

- 标准中后台布局：左侧菜单 + 顶部面包屑/用户区 + 内容区。
- 统一表格 + 筛选 + 分页 + 操作列；关键操作二次确认。
- 审核工作台：作品待审核列表，一键通过/驳回 + 备注，高效流转。
- 权限控制：按 RBAC 隐藏无权限的菜单与按钮。
- Dashboard：图表展示核心指标（Ant Design Charts / ECharts）。

## 六、跨端共享能力

- **请求封装**：Axios 实例统一 baseURL、token 注入、错误码映射、401 跳登录、业务码提示。
- **鉴权流程**：登录后保存 token 与用户信息；路由守卫控制登录态。
- **空间上下文**：用户端全局维护当前空间 id，随空间切换刷新相关数据。
- **任务轮询 hook**：`useTask(taskId)` 统一处理进度轮询与完成态。
- **文件直传**：获取预签名 URL → 直传 S3 → 回执关联业务对象。
- **偏好设置 store**：维护主题 / 语言 / 思考等级等偏好，应用主题样式、语言包。
- **画布状态 store**：自由画布节点 / 连线 / 位置 / 会话状态管理。
- **技能库选择组件**：通用设置中选用画面风格、导演叙事技能等。

## 八、设计规范与质量

- 组件可复用、命名清晰；样式与逻辑分离。
- 无障碍：键盘可操作、对比度、可访问性标注。
- 性能：路由懒加载、图片懒加载、列表虚拟滚动（信息流）。
- 视觉质量：参考 web 设计指南，避免"模板感"，打造独特品牌识别。
