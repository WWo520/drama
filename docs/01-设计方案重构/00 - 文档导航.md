## B. 数据真源铁律总表（争议裁决 · 全团队强制执行）

| 争议问题 | 唯一真源文档 + 章节 | 禁止动作 |
|---|---|---|
| 枚举值（status/type/payment_status） | [10 - 数据库设计.md](./10%20-%20数据库设计.md) A 章 `CREATE TYPE` SQL | 禁止任何代码/接口/前端 TS enum 自定义值，必须从此生成 |
| 接口路径 / HTTP Method / Query 参数命名 | [05 - 接口文档.md](./05%20-%20接口文档.md) D 章 `paths:` 定义 | 后端路由、前端 Query Key 必须完全对齐，禁止自定义路径（如 `/project/new`） |
| 请求 Body / 响应 JSON 字段名 + 类型 + nullable | 05 E 章 `components/schemas:` | 禁止后端 go struct json tag、前端 DTO 与 Schemas 不一致（含大小写） |
| 通用响应包装 `ApiResponse<T>` | 05 A/B 章 | 禁止后端裸返回不包装；禁止前端错误解包 `res.data.data` |
| 错误码 → Toast 文案映射 | 05 C 章错误码字典（9 大类 40+ 细分码） | 禁止后端返回字典外 code；禁止前端硬编码 toast 文案，一律拦截器映射 |
| WebSocket 消息协议 | 05 F 章（服务端 10 种 + 客户端 4 种） | 消息名/字段大小写、心跳间隔/超时/重连退避数值必须一致 |
| 文件上传预签名 | 05 G 章（PUT 15min / GET 24h） | 有效期/路径按契约，禁止私自改 |
| 功能验收条件 / E2E 步骤 / 状态机转移 | [03 - 功能文档.md](./03-功能模块/03%20-%20功能文档.md) 正文 + 附录 | 禁止 QA 自写验收条件与文档不对齐 |
| 扣费/冻结/解冻时机 | [04 - 后端方案.md](./04%20-%20后端方案.md) 计费事务设计章 + 03 附录 | 禁止绕过 `generation_tasks.frozen_points` 三字段直接扣 balance |
| 排期/里程碑/晋级门槛 | [09 - 分期路标.md](./09%20-%20分期路标.md) | 禁止在其他文档私自定义排期 |
| 概念层 ER 关系 | [02 - 数据模型.md](./02%20-%20数据模型.md) A 章 ASCII 图 | 实体间引用关系以此为准 |
| 数据一致性规则（幂等/跨集复用） | 02 D 章 | 积分扣减/幂等/跨集复用判定以此为准 |
| DDL/索引/Redis Key 实现 | [10 - 数据库设计.md](./10%20-%20数据库设计.md) B 章起 | 建表/索引/Redis 设计一律以 10 为准 |
| 管理端菜单/按钮级权限来源 | 02 `roles.permissions` JSONB 字段 | 前端 `adminRbacLoader` 按此校验，禁止硬编码菜单 |
| 表名/命名口径 | 02 ER 图 + 10 B 章表名 | 禁止表名单复/复数/下划线不一致（如 `three_d_scenes` vs `3d_scenes`） |
