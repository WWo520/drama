## 六、里程碑晋级门槛铁律

**M0→M1 晋级（第 6 周周末开评审会），以下条件全部 AND 满足**：

1. G1 技术成功率 ≥ 门槛的 70% 达成率
2. G2 付费转化率 ≥ 门槛的 70% 达成率，且至少 2 人/50 人付费
3. G3 首片时长 ≤ 门槛的放宽上限
4. E2E 核心用例 100% 全通过
5. 代码 Bug：P0 级 0 个未修 / P1 级 ≤ 5 个未修

处理规则：全部满足 → 下周启动 M1；任一项不满足 → 冻结 M1 新功能 1~2 周集中修；连续 2 周评审仍不通过 → 产品/技术负责人复盘降级方案（缩功能或延周期）。

**M1→M2 / M2→V2 同逻辑**：对应阶段指标 ≥ 80% + 所有 E2E 对应 ≥ 95% 通过才晋级。
