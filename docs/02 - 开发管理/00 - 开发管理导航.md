## 3. 阶段映射

| 阶段 | 执行层工作包 | 进入条件与范围 |
|---|---|---|
| M0 | 基础底座、创作任务、视频导出、支付、用户端、最小管理端、质量恢复 | 以 `09` 的 M0 范围和 M0→M1 门禁为准 |
| M1 | 空间协作与共享积分、画布、变体复用、会员与多轨、回归 | 以 `09` 的 M1 范围和 M1→M2 门禁为准 |
| M2 | 生态、审核与接单、模板样式、管理开放能力、部署上线 | 以 `09` 的 M2 范围和上线验收为准 |

## 4. 更新责任

- 任务负责人更新任务状态、交付物、证据与阻塞原因。
- 验收人只在证据可访问且符合对应真源后，将任务推进至完成。
- 设计、契约、DDL 和排期发生变化时，先更新其唯一真源，再回写本目录的关联链接、影响范围和任务状态。
- 没有证据路径的任务不得标记为完成；待定上线参数不得以“默认值”代替定案。
