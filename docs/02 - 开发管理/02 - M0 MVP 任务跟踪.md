# M0 MVP 任务跟踪

> 范围、排期和晋级门槛以 [09 - 分期路标](../01%20-%20设计方案/09%20-%20分期路标.md) 的 M0 与 M0→M1 章节为准。本页仅维护执行状态与证据。

## 工作包总览

| ID | 工作包 | 前置依赖 | 交付与验收证据 | 状态 | 阻断 |
|---|---|---|---|---|---|
| M0-BASE | 基础工程与迁移 | 无 | 工程启动、M0 迁移、空库/基线库记录、AI Adapter 测试 | BACKLOG | 无 |
| M0-AUTH | 认证与安全基线 | M0-BASE | 注册登录登出、令牌生命周期、认证审计与安全验证 | BACKLOG | 无 |
| M0-TASK | 任务投递与 Worker | M0-BASE | Outbox、调度、回调幂等、故障恢复与账本证据 | BACKLOG | 无 |
| M0-CREATE | Step1/Step2 创作链路 | M0-AUTH、M0-TASK | 项目与资产链路、冻结/解冻、E2E | BACKLOG | 无 |
| M0-VIDEO | Step3/Step4 视频导出 | M0-CREATE、M0-TASK | 分镜、视频、导出下载、回调与恢复 E2E | BACKLOG | 无 |
| M0-BILLING | 积分与支付 | M0-AUTH、M0-BASE | 充值、验签、订单流水原子性、重复回调验证 | BACKLOG | 无 |
| M0-CLIENT | 用户端与最小管理端 | M0-AUTH、M0-CREATE、M0-BILLING | 核心页面、权限、WS/轮询降级、UI E2E | BACKLOG | 无 |
| M0-QUALITY | 契约、质量与恢复演练 | 所有 M0 工作包 | OpenAPI/枚举校验、E2E、恢复、性能与缺陷清单 | BACKLOG | 无 |

## 工作包卡片

### M0-BASE 基础工程与迁移

- **真源**：[09](../01%20-%20设计方案/09%20-%20分期路标.md)、[数据库设计](../01%20-%20设计方案/02%20-%20数据库设计.md)、[系统架构](../01%20-%20设计方案/01%20-%20系统架构.md)
- **交付物**：运行环境、基础工程、M0 实际迁移集合、备份可恢复验证、模型 Adapter。
- **验收证据**：环境启动日志；迁移在空库和基线库的执行记录；Adapter 单测报告；备份恢复记录。
- **阻断条件**：迁移拓扑或回滚策略不明确；基础环境不可复现。

### M0-AUTH 认证与安全基线

- **真源**：[账号登录](../01%20-%20设计方案/03-功能模块/03-01%20-%20账号登录功能.md)、[接口文档](../01%20-%20设计方案/05%20-%20接口文档.md)、[后端方案](../01%20-%20设计方案/04%20-%20后端方案.md)
- **交付物**：注册、登录、刷新、登出、权限中间件、认证审计与登录防护。
- **验收证据**：认证契约校验；令牌轮换/失效/复用测试；跨站防护测试；登录审计记录。
- **阻断条件**：认证 Cookie、CSRF/CORS、令牌轮换或密码哈希口径未与真源一致。

### M0-TASK 任务投递与 Worker

- **真源**：[后端方案](../01%20-%20设计方案/04%20-%20后端方案.md)、[功能文档 E.3](../01%20-%20设计方案/03-功能模块/03%20-%20功能文档.md)、[数据库设计](../01%20-%20设计方案/02%20-%20数据库设计.md)
- **交付物**：任务、冻结和 Outbox 同事务；Dispatcher；Worker 租约、重试、死信、人工重放与状态裁决。
- **验收证据**：重复提交、重复/乱序回调、发布器/Worker 崩溃、Redis 重启、死信重放及单次结算记录。
- **阻断条件**：Redis 被作为唯一可靠投递来源；无法证明积分仅冻结/结算一次。

### M0-CREATE / M0-VIDEO 创作与视频闭环

- **真源**：[创作中心](../01%20-%20设计方案/03-功能模块/03-03%20-%20创作中心功能.md)、[功能文档](../01%20-%20设计方案/03-功能模块/03%20-%20功能文档.md)、[接口文档](../01%20-%20设计方案/05%20-%20接口文档.md)
- **交付物**：从剧本输入、资产、分镜与视频生成到成片导出和下载的完整链路。
- **验收证据**：对应 E2E、上传 complete 校验、播放/下载记录、异常回调和重试结果。
- **阻断条件**：关键路径未形成端到端可复现证据。

### M0-BILLING / M0-CLIENT / M0-QUALITY

- **真源**：[商业会员](../01%20-%20设计方案/03-功能模块/03-08%20-%20商业会员功能.md)、[后端方案](../01%20-%20设计方案/04%20-%20后端方案.md)、[09](../01%20-%20设计方案/09%20-%20分期路标.md)
- **交付物**：支付与账本闭环、用户端/最小管理端、契约冻结、枚举生成、全量 E2E 与恢复验证。
- **验收证据**：支付沙箱回调、账本抽样对账、前端 E2E、WS 断连降级、缺陷清单、性能与恢复报告。
- **阻断条件**：账本差异、核心 E2E 失败、P0 未关闭或 M0 门禁证据缺失。

## 阶段出口

M0 结束时逐项填写 [阶段门禁与证据清单](./05%20-%20阶段门禁与证据清单.md) 的 `G-M0-*`；未通过项不得仅通过修改工作包状态消除。
