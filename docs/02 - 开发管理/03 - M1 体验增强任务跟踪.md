# M1 体验增强任务跟踪

> 阶段范围、进入前提和晋级门槛以 [09 - 分期路标](../01%20-%20设计方案/09%20-%20分期路标.md) 的 M1 与 M1→M2 章节为准。本页不定义新的交付日期或指标。

## 工作包总览

| ID | 工作包 | 前置依赖 | 交付与验收证据 | 状态 | 阻断 |
|---|---|---|---|---|---|
| M1-SCHEMA | M1 迁移与依赖拓扑 | M0 门禁通过 | 实际扩表清单、外键拓扑、空库/M0 基线库迁移与回滚 | BACKLOG | 未确认拓扑不得开始首条 M1 迁移 |
| M1-SPACE | 空间协作与共享积分 | M1-SCHEMA | 团队账户、权限、历史归因、账本和并发验证 | BACKLOG | 无 |
| M1-CANVAS | 自由画布与执行工作流 | M1-SCHEMA、M1-SPACE | 节点/连线、保存恢复、任务执行、故障恢复 | BACKLOG | 无 |
| M1-CREATE | 多变体、历史版本与跨集复用 | M1-SCHEMA、M1-SPACE | 版本回滚、变体、复用豁免扣费 E2E | BACKLOG | 无 |
| M1-MONETIZE | 会员、订阅与多轨编辑 | M1-SCHEMA、M0-BILLING | 首购、续期、取消、三轨导出与账本 | BACKLOG | 无 |
| M1-REGRESSION | 回归与晋级验证 | 其他 M1 工作包 | 受影响 E2E、迁移、账本和故障恢复报告 | BACKLOG | 无 |

## 工作包卡片

### M1-SCHEMA 迁移与依赖拓扑

- **真源**：[09](../01%20-%20设计方案/09%20-%20分期路标.md)、[数据库设计](../01%20-%20设计方案/02%20-%20数据库设计.md) D.2。
- **必须先完成**：实际扩表清单、外键拓扑和迁移/回滚方案；再编写首条 M1 迁移。
- **证据**：真源变更记录、空库及 M0 基线库迁移日志、回滚/兼容说明。

### M1-SPACE 空间协作与共享积分

- **真源**：[空间协作](../01%20-%20设计方案/03-功能模块/03-02%20-%20空间协作功能.md)、[功能文档 E.1](../01%20-%20设计方案/03-功能模块/03%20-%20功能文档.md)、[后端方案](../01%20-%20设计方案/04%20-%20后端方案.md)。
- **交付物**：团队空间、邀请、角色隔离、空间账户、不可变账务归因与成员消耗视图。
- **证据**：并发冻结、余额不足不入队且不扣个人、越权拦截、退出成员历史对账、重复/乱序回调单次结算。
- **阻断条件**：客户端可指定扣费账户；历史账务随当前角色变化回算；账本存在差异。

### M1-CANVAS 自由画布与执行工作流

- **真源**：[功能文档 E.4](../01%20-%20设计方案/03-功能模块/03%20-%20功能文档.md)、[接口文档](../01%20-%20设计方案/05%20-%20接口文档.md)、[数据库设计](../01%20-%20设计方案/02%20-%20数据库设计.md)。
- **交付物**：画布节点、连线校验、保存、恢复、执行与状态回填。
- **证据**：模板完整运行、保存恢复、断连/刷新不中断执行、非法连线拒绝、故障恢复报告。

### M1-CREATE 与 M1-MONETIZE

- **真源**：[创作中心](../01%20-%20设计方案/03-功能模块/03-03%20-%20创作中心功能.md)、[商业会员](../01%20-%20设计方案/03-功能模块/03-08%20-%20商业会员功能.md)、[09](../01%20-%20设计方案/09%20-%20分期路标.md)。
- **交付物**：版本/变体/复用、订阅生命周期、首购权益、多轨编辑与导出。
- **证据**：版本回滚、跨集免扣、首购/到期/取消、导出与计费对账 E2E。

### M1-REGRESSION 阶段回归

- **真源**：[09](../01%20-%20设计方案/09%20-%20分期路标.md) 五章、[功能文档](../01%20-%20设计方案/03-功能模块/03%20-%20功能文档.md)。
- **证据**：新增及受影响 E2E、迁移可重复执行、账本抽样、缺陷与恢复演练结果。
- **出口**：逐项填写 [阶段门禁与证据清单](./05%20-%20阶段门禁与证据清单.md) 的 `G-M1-*`。
