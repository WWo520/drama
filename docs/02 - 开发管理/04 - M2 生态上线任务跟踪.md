# M2 生态上线任务跟踪

> 阶段范围、进入前提和上线验收以 [09 - 分期路标](../01%20-%20设计方案/09%20-%20分期路标.md) 的 M2 章节为准。本页记录实际工作与放行证据；不将 [S-02](../01%20-%20设计方案/待办/S-02%20-%20上线合规与运维手册.md) 的占位内容视为已落地。

## 工作包总览

| ID | 工作包 | 前置依赖 | 交付与验收证据 | 状态 | 阻断 |
|---|---|---|---|---|---|
| M2-SCHEMA | M2 迁移与依赖拓扑 | M1 门禁通过 | 实际扩表、外键拓扑、迁移与回滚证据 | BACKLOG | 未确认拓扑不得开始首条 M2 迁移 |
| M2-ECOSYSTEM | 发现社区与审核 | M2-SCHEMA | 公开、互动、举报、审核闭环 E2E | BACKLOG | 无 |
| M2-MARKET | 任务接单、模板与样式 | M2-SCHEMA | 接单、模板市集、样式初始化与验收 | BACKLOG | 无 |
| M2-ADMIN-API | 管理端与开放平台 | M2-SCHEMA、M2-ECOSYSTEM | RBAC、运营财务、API Key、Webhook 与审计 | BACKLOG | 无 |
| M2-OPS | 部署、可观测性与灾备 | M0-QUALITY | 环境、仪表盘、告警、备份恢复、容量与降级 | BACKLOG | S-02 待定参数 |
| M2-RELEASE | 发布、灰度与回滚 | M2-OPS、其他 M2 工作包 | 发布审批、灰度、回滚、全量回归与放行记录 | BACKLOG | S-02 待定参数 |

## 工作包卡片

### M2-SCHEMA 迁移与依赖拓扑

- **真源**：[09](../01%20-%20设计方案/09%20-%20分期路标.md)、[数据库设计](../01%20-%20设计方案/02%20-%20数据库设计.md) D.3。
- **前置**：M2 实际扩表范围和外键拓扑顺序必须先回写真源。
- **证据**：迁移依赖图、空库/M1 基线库执行、数据校验、回滚或兼容策略。

### M2-ECOSYSTEM / M2-MARKET

- **真源**：[作品发布](../01%20-%20设计方案/03-功能模块/03-04%20-%20作品发布功能.md)、[任务接单](../01%20-%20设计方案/03-功能模块/03-05%20-%20任务接单功能.md)、[发现互动](../01%20-%20设计方案/03-功能模块/03-06%20-%20发现互动功能.md)、[功能文档](../01%20-%20设计方案/03-功能模块/03%20-%20功能文档.md)。
- **交付物**：作品发布审核、举报处置、发现互动、接单、模板和样式。
- **证据**：权限/状态迁移、审核记录、举报/申诉、SEO 页面、模板购买或使用流程 E2E。
- **阻断条件**：审核路径、权限、发布记录或审计链无法闭环。

### M2-ADMIN-API 管理端与开放平台

- **真源**：[管理端功能](../01%20-%20设计方案/03-功能模块/03-11%20-%20管理端功能.md)、[接口文档](../01%20-%20设计方案/05%20-%20接口文档.md)、[数据库设计](../01%20-%20设计方案/02%20-%20数据库设计.md)。
- **交付物**：管理端能力、双因子、审计、运营财务视图、API Key 与 Webhook。
- **证据**：权限矩阵、配置生效、死信重放、报表对账、Key 鉴权、Webhook 交付与重试测试。

### M2-OPS 部署、可观测性与灾备

- **真源**：[09](../01%20-%20设计方案/09%20-%20分期路标.md)、[S-02](../01%20-%20设计方案/待办/S-02%20-%20上线合规与运维手册.md)、[后端方案](../01%20-%20设计方案/04%20-%20后端方案.md)。
- **交付物**：部署制品、监控告警、容量压测、备份/PITR、恢复演练、第三方故障策略。
- **阻断条件**：S-02 中责任人、阈值、频率、证据或放行条件尚未定案；无恢复和容量实测证据。

### M2-RELEASE 发布、灰度与回滚

- **真源**：[09](../01%20-%20设计方案/09%20-%20分期路标.md)、[S-02](../01%20-%20设计方案/待办/S-02%20-%20上线合规与运维手册.md)。
- **交付物**：版本、审批、灰度观测、应用/数据库/异步任务回滚和上线结论。
- **证据**：发布单、制品与配置版本、各灰度档观测、回滚演练、财务对账和安全报告。
- **出口**：逐项填写 [阶段门禁与证据清单](./05%20-%20阶段门禁与证据清单.md) 的 `G-REL-*`。
