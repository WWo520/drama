# 阶段门禁与证据清单

> 门槛、指标公式和阶段范围只引用 [09 - 分期路标](../01%20-%20设计方案/09%20-%20分期路标.md)。本文件将其转化为评审记录，不重复定义数值或替代裁决。

## 1. 使用规则

- 每一项均需填写责任人、证据路径、执行日期、结论和阻断问题。
- 结论只能是“通过 / 不通过 / 待验证 / 不适用（附批准依据）”。
- 任一必须项不通过或待验证，阶段不得晋级；具体处理以 `09` 为准。

| 字段 | 内容 |
|---|---|
| 门禁 ID | 阶段与序号，例如 `G-M0-01` |
| 真源链接 | 对应 `09`、`03`、`05`、`02` 或 `S-02` 的精确章节 |
| 责任人 | 交付责任角色或姓名 |
| 证据路径 | 报告、日志、录像、仪表盘、迁移或审批记录 |
| 执行日期 | 实际执行日期 |
| 结论 | 通过 / 不通过 / 待验证 / 不适用 |
| 阻断问题 | 关联 `06` 编号；无则填“无” |
