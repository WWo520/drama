# 风险问题与变更管理

> 本文记录执行事实和决策留痕。设计、接口、DDL、排期的内容变更必须回写对应唯一真源；本文件不能单独改变任何真源。

## 1. 记录模型

| 类型 | 用途 | 最小字段 |
|---|---|---|
| 风险 | 尚未发生、可能影响目标的事项 | ID、概率、影响、触发条件、缓解措施、负责人、关联任务 |
| 问题 | 已发生且需要处理的偏差或缺陷 | ID、严重级别、复现/证据、影响、临时措施、根因、负责人 |
| 阻塞 | 无法继续推进的外部依赖或未决策事项 | ID、阻塞任务、所需输入、决策人、升级时间 |
| 变更 | 已批准的范围、契约、DDL、排期或实现调整 | ID、变更原因、影响分析、真源回写、批准记录、回滚方案 |

## 2. 严重级别与升级

| 级别 | 判定 | 处理规则 |
|---|---|---|
| P0 | 资金、数据完整性、安全、合规、核心链路或上线放行风险 | 立即阻断受影响发布/晋级；记录负责人和恢复证据 |
| P1 | 主路径明显降级、阶段门禁受影响或无可靠替代 | 当前工作周期内明确方案；未解决不得隐性关闭 |
| P2 | 非核心功能、可绕行或体验问题 | 纳入工作包并跟踪优先级 |
| P3 | 不阻断交付的优化或文档改善 | 记录后按容量处理 |

## 3. 真源联动

| 变更类型 | 必须先更新的真源 | 执行层动作 |
|---|---|---|
| 功能、验收、E2E、状态机 | `03 - 功能文档` | 更新关联工作包、测试和门禁证据 |
| API、DTO、错误码、WS | `05 - 接口文档` | 重新生成/校验契约并评估前后端影响 |
| DDL、枚举、索引、Redis Key、迁移顺序 | `02 - 数据库设计` | 补迁移、回滚和空库/基线库验证 |
| 调度、事务、支付、Worker | `04 - 后端方案` | 补故障注入、幂等和恢复证据 |
| 排期、范围、门槛 | `09 - 分期路标` | 更新工作包映射，不在本目录自行改期 |
| 合规或运维参数 | `S-02` 及关联设计真源 | 明确责任人、定案记录、演练和放行结论 |

## 4. 记录模板

```text
ID:
类型 / 严重级别:
状态: OPEN | MITIGATING | RESOLVED | ACCEPTED
定位证据:
影响范围:
关联真源与章节:
关联任务/门禁:
决策或最小修复:
负责人 / 验收人:
截止条件（不是排期）:
证据路径:
结论:
```
