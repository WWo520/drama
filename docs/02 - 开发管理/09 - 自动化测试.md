## 二、问题登记

| # | 页面/功能点 | 问题描述 | 严重级 | 建议 |
|---|------------|---------|-------|------|
| B1 | 用户管理／新增用户 | adminCreateUser 插入 `phone=''` 撞 `idx_users_phone` 唯一索引(`WHERE phone IS NOT NULL` 对空串生效)，第二次起所有新增均报"邮箱已被注册"；前端弹窗静默失败无错误提示 | P1 | ① admin_extra_service.go: 当 phone 空时写 NULL 而非 ''；② 检查 000003 迁移的 `WHERE phone IS NOT NULL` 索引语义；③ 前端 catch 显示后端错误文案 |
| B2 | 内容审核／通过/驳回 | `jsonb_build_object('status',$5)` pgx 无法推断参数类型 `$5`(SQLSTATE 42P18) | P1 | content_store.go:133 改 `$5::text` |
| B3 | 内容审核／撤下 ／作品管理／删除 | `publish_action_enum` 枚举值缺失 `'REVOKE'`，3 处代码(content_store.go Revoke、admin_store.go DeleteWork、AdminWorksPage)写入该值导致 22P02 | P1 | ① 迁移 ALTER TYPE publish_action_enum ADD VALUE 'REVOKE'(注意事务外执行)；② 清理代码中写入 REVOKE 的 3 处确保枚举一致 |
| B4 | 用户管理／积分调整 | PUT /admin/users/:uuid/points 稳定 500，代码审查未发现直接错误 | P2 | 后端日志排查(代码在 admin_extra_service.go UserPoints) |

| B6 | 多页面 | 数据库多处中文乱码(模型名 DeepSeek V3 ?? / 任务列表 ????) | P2 | 数据库连接字符集/迁移种子数据编码不一致，清数据后重新 seed |
| B7 | 会员套餐编辑 | 价格输入框回显浮点精度 9.899999618530273(应为 9.90) | P2 | 前端 `String(data.price_yuan)` → `String(Number(data.price_yuan).toFixed(2))` |
