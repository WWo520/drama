>
> 方法：浏览器双端扫描对比。对 luxreal.com 官方站点与我们已对齐的前端（web-user，localhost:5173）逐页采集 **getComputedStyle 实测值**（截图通道故障，已降级为 DOM 精确测量，数值可信度高于目视截图）。

## 三、有意保留的差异（不对齐）

| 差异 | 我方现状 | 保留理由 |
|---|---|---|
| 独立登录页 | 光球动效 + 网格线 Hero | 品牌展示位；官方是应用内弹窗 |
| 首页精选推荐轮播 | 4 张卡、每 4s 自动切换、含"限时创作挑战赛"横幅 | 已立项的产品规范（见视觉保真规范记忆），官方为 3 张静态横幅 |
| 页脚 | 有简短页脚 | 国内合规与品牌露出需要 |
| 作品页规整网格 | grid-cols-4 | 卡片是"项目"而非"视频"，信息密度与操作区需求不同 |
| 字重略重（800 标题） | H1 56px/800 | 若产品确认品牌调性可保留，否则按 H-05 收敛 |
| 通知/消息入口 | 代码已有 NotificationsPage，暂无导航入口 | 待消息中心批次排期，与视觉对齐无关 |

## 四、建议实施顺序

1. **第一梯队（P1，建议合并为一个批次）**：T-01 令牌收敛 → G-01 侧栏激活态 → G-03 公告栏 → H-01/H-02 首页底色与容器 → F-01/F-03 发现页分类条与视频预览 → B-01/B-02 套餐卡光晕与对比表。
2. **第二梯队（P2）**：T-02~T-04 令牌工程化 + 各页细节（圆角/字重/渐变统一）。
3. **豁免项**：第三节所列差异如需变更，须产品确认后单独立项。
