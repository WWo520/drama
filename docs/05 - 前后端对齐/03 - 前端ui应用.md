# 03 - 前端 UI 应用（设计稿 → React 页面保真实施方案）

> **文档日期**: 2026-08-17
> **设计稿源**: `docs/04 - 前端ui设计/luxreal-clone`（design 注册 17 页，HTML 已产出 13 页 + colors_and_type.css + TASK_MANAGEMENT.md 设计规格）
> **目标**: React 前端（web-user 用户端 + web-admin 管理端，按 design 注册 17 页）渲染结果与设计稿**逐像素一致**
> **总原则**: 设计稿是唯一视觉真相，React 只做「结构拆分 + 数据注入 + 交互托管」，禁止任何视觉改动

---

## 一、设计规格总纲（来自 TASK_MANAGEMENT.md，融合时强制遵循）

### 1.1 全局布局体系

```
总视口 = 72px（主导航） + 220px（剧集侧栏，仅工作台） + 主内容区（flex-1）
```

| 要素 | 规格 |
|------|------|
| 主导航 | 72px 宽、纯黑 `#000000`；Logo = 几何 L 形白色 SVG；图标列表（创作/发现/作品/消息带红点徽章/充值紫色渐变/头像渐变圆形+Y字母） |
| 剧集侧栏（仅工作台） | 220px 宽、`#111111`；返回按钮 + 项目名 + 剧集卡片（蓝边框高亮）+ 纯文本叙事单元列表（**无树形展开交互**）+ 新增剧集按钮 |
| 工作流步骤 | **居中胶囊（pill）**，非全宽顶栏；`absolute left-1/2 -translate-x-1/2`；当前步骤蓝紫渐变+发光；毛玻璃效果 |
| 顶部栏 | 单行结构：左侧 `w-[200px]` 占位 + 居中胶囊 + 右侧页面特有按钮 |
| 底部浮动操作栏 | 资产生成/视频制作页：居中悬浮药丸形按钮组（fixed 定位） |
| 右下角浮动按钮组 | 每页固定两个圆形按钮（团队协作 + 客服），容易遗漏 |
| 内容区 padding | 所有页面内容区 `px-6` 左右 padding |

### 1.2 各页面内容宽度（差异化，禁止统一化）

| 页面 | 内容宽度 | 实现 | 原因 |
|------|---------|------|------|
| 剧本拆分 | ~65% | `max-width:65%` + `mx-auto` | 信息密度低，窄更易读 |
| 资产生成 | 接近全宽 | 无 max-width，仅 `px-6` | 资产网格需空间 |
| 视频制作 | ~85% | `max-width:85%` + `mx-auto` | 镜头卡需要空间但留边聚焦 |
| 成片预览 | 播放器 max 400px | `max-width:400px` + `flex justify-center` | 竖屏 9:16，高 68vh |

> 百分比相对**主内容区**（减去 72px+220px 后），非整个视口。

### 1.3 色彩与质感规范

| 项 | 规格 |
|----|------|
| 卡片 | **低饱和度深灰 `#1E1E24`**，非蓝色调（早期版本蓝紫卡片已被否定） |
| 激活态/当前步骤 | 蓝紫渐变 `linear-gradient(135deg,#4C7FF8,#8B5CF6)` + 发光 |
| 边框 | `#2A2A35` |
| 背景 | `#0D0D0D` |
| 字体 | `-apple-system, "PingFang SC", "Microsoft YaHei"` |
| 图标 | Lucide（`folder` 而非 `folder-open`；充值用文字"充值"非数字） |
| 视觉基调 | **克制**：只有交互元素用渐变，其余全部深灰 |

### 1.4 各工作台页顶部右侧按钮差异

| 页面 | 右上按钮 |
|------|---------|
| 剧本拆分 | 自由画布 Beta 入口 + Agent 技能配置 + 最小化 |
| 资产生成 | 3D 片场 + 添加 + 最小化 |
| 视频制作 | 本集总时长 xx秒 + 最小化 |
| 成片预览 | 1080P + 9:16 + 最小化 |

## 二、融合三步法（每页统一流程）

```
第 1 步 搬 CSS：HTML 里 <style>...</style> 整块 → pages/{page}/{page}.css（类名一个都不改）
第 2 步 拆 DOM：<body> 按区块拆成 React 组件（class="x" → className="x"，其他原样）
第 3 步 换数据：内嵌 mock 区块 → TanStack Query（渲染模板不变，只换数据源）
```

### 铁律（违反视为 Bug）

| # | 纪律 |
|---|------|
| 1 | CSS **原样复制**：禁止重写/整理/"优化"/改命名 |
| 2 | DOM **1:1 复制**：只做 JSX 语法转换，层级顺序不动 |
| 3 | **禁止混用 Tailwind 类**替换设计稿自定义类（web-admin 例外：admin 页设计稿本身用 Tailwind） |
| 4 | **禁止顺手美化**：视觉调整必须先改设计稿再同步代码 |

## 三、React 工程应用结构

### 3.1 共用布局外壳 → AppShell 组件（设计稿"基准页规则"的 React 化）

设计稿的共用元素（侧边栏/工作流胶囊/浮动按钮）在 4 个工作台页内联重复，React 化时**抽成共享组件**（这正是 TASK_MANAGEMENT.md 遗留的优化方向①）：

```
apps/web-user/src/
├── layouts/
│   ├── AppShell.tsx          # 72px 主导航 + 内容区（前台 3 页 + 工作台共用）
│   ├── WorkbenchShell.tsx    # AppShell + 220px 剧集栏 + 顶部栏（左占位+居中胶囊+右按钮插槽）+ 右下角浮动按钮
│   └── shell.css             # ← 从 workbench-script.html（基准页）提取的共用布局 CSS
├── components/
│   ├── WorkflowPill.tsx      # 居中工作流胶囊（步骤高亮蓝紫渐变）
│   ├── FloatingActionBar.tsx # 底部悬浮操作栏（资产/视频页）
│   ├── CornerFabs.tsx        # 右下角浮动按钮组（团队+客服）
│   └── ProfilePopover.tsx    # 头像下拉（用户信息/登出）
└── pages/（各页组件 + 各自 CSS，拆分清单见本文第四节"15 页应用规格速查"与 04 文档第六节逐页转换清单）
```

**基准页规则**：共用布局以 `workbench-script.html` 为准；React 化后共用布局只有一份（AppShell/WorkbenchShell），天然解决"7 页同步"问题。

### 3.2 布局外壳 DOM 对照（WorkbenchShell）

```
设计稿:  <div 72px导航> <div 220px剧集栏> <div flex-1 主内容区>
React:   <AppShell> <EpisodeSidebar> <main className="flex-1">
                                  ├── <TopBar> [左占位] <WorkflowPill/> [右按钮插槽]
                                  └── <内容滚动区>{children}</内容滚动区>
```

### 3.3 宽度体系在 React 的落地

各页面内容宽度直接由搬入的 CSS 控制（`max-width:65%/85%/400px` + `mx-auto`），React 不改动——宽度逻辑属于视觉层，遵循铁律①。

## 五、保真验收流程（每页融合完成后必做）

```
1. 启动设计稿本地服务: cd luxreal-clone && python -m http.server 8901
2. 设计稿页面（http://localhost:8901/pages/xxx.html）与 React 页面（http://localhost:5173/xxx）左右并排
3. Chrome DevTools 同视口 1440×900 截图对比
4. 逐区块检查清单：
   □ 侧边栏 72px 主导航（Logo 形状/图标/徽章/头像字母）
   □ 剧集侧栏 220px（剧集卡蓝边框/单元纯文本列表）
   □ 顶部栏单行结构（左占位/居中胶囊/右按钮）
   □ 内容宽度（65%/85%/全宽/400px 各页不同）
   □ 卡片质感（深灰 #1E1E24，非蓝色调）
   □ 底部浮动操作栏 / 右下角浮动按钮
   □ 悬停态/弹窗/滚动行为
5. 验收标准：无肉眼可见差异 → 通过；有差异 → 回查四条铁律哪条被破坏
```

> 项目既有 `Chrome DevTools UI 对齐测试方法论`（记忆库）直接复用。

## 六、例外与边界

| 例外 | 说明 |
|------|------|
| 路由跳转 | `<a href="xxx.html">` → `<Link to="/xxx">`，类名/CSS 不变 |
| 弹窗条件渲染 | `classList.toggle('visible')` → `className={open ? 'x visible' : 'x'}` |
| 列表循环 | 写死卡片 → `map()`，卡片 DOM 模板逐字保留 |
| 共用布局抽组件 | 4 页内联重复的侧边栏 CSS → AppShell 一份（类名/CSS 原文搬入，仅去重） |
| 品牌名 | 可见 LuxReal 字样 → Empty Broken；CSS 类前缀 `luxreal-` 不变 |
| 全局 reset | 仅必要 box-sizing reset（设计稿已有则不加） |

**不迁移**：`.preflight/`、`runtime-*.json`、`validation-report.json`、`CONVERSATION_HISTORY.md` 是设计工具痕迹；`luxreal-clone.design` 是画布项目文件——均与 React 工程无关。
