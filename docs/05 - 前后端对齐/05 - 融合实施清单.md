> **创建日期**: 2026-08-18
> **状态**: 登录页（LoginPage）已完成融合并通过视觉核验，作为后续页面的模板范例

## 一、融合三原则

1. **主链路优先**：先打通「创作入口 → 剧本拆分 → 资产 → 视频 → 导出」产品核心闭环，周边页（发现/充值/通知）和管理端靠后
2. **基准页先行**：workbench-script.html 是共用布局（72px 导航/220px 剧集栏/胶囊工作流/浮动按钮）的基准页，先融合它并提取 AppShell/WorkbenchShell，其余 3 个工作台页只需转内容区（工时减半）
3. **每页独立验收**：每页按 03 文档第五节流程做并排截图对比，通过后再进下一页，不允许积压差异

## 四、每页融合执行模板(照抄执行)

```
第 1 步 搬 CSS:设计稿 <style> 块 → pages/{page}/{page}.css(零修改)
第 2 步 拆 DOM:<body> → JSX(04 文档第三节映射表),类名/层级不动
第 3 步 拆组件:重复/独立区块 → 子组件(05-03 文档 3.5 清单)
第 4 步 转交互:内联 script → hooks(04 文档第四节对照表)
第 5 步 接数据:静态 mock → api-client 调用(01 文档第四节映射表)
第 6 步 验收:设计稿 8901 端口 vs 5173 并排截图,零差异通过
```
