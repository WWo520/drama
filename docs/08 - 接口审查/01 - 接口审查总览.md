# 接口审查总览：前端功能点 × 后端接口覆盖

> 审查日期：2026-08-20
> 审查范围：`apps/web-user`（用户端）+ `apps/web-admin`（管理端）全部页面/组件功能点，对照 `duanju-backend/internal` 全部路由注册与处理器实现。
> 审查方式：静态代码扫描。前端以「页面实际发起的 HTTP/WS/SSE 请求」为准（含 `@duanju/api-client` 封装与页面内直接 `api.*` 调用），后端以 `router.go` + `handler.go` + auth/space handler 的路由注册为准。

---

## 1. 总体结论

| 维度 | 数量 |
| --- | --- |
| 后端已注册接口（去重） | 约 160 个（含公开 / 鉴权 / 管理 / WS / SSE） |
| 前端实际调用的接口 | 约 85 个 |
| 前端功能点（按页面拆分） | 用户端 17 页 / 组件 + 管理端 9 页 8 大模块 |
| 前端功能点 **有后端接口支撑** | ✅ 绝大多数 |
| 前端功能点 **无后端接口**（纯本地/静态/占位） | ⚠️ 见 §4（重点：创作页「模型配置」弹窗） |
| 后端已实现 **但前端未接入** 的接口 | ⚠️ 见 §5（约 50 个，多为 S3/S5 补齐的进阶能力） |

**一句话结论**：核心创作闭环（剧本 → 拆分 → 资产生成 → 视频生成 → 导出）、账户/计费、空间协作、内容广场、管理端各页面均已前后端打通；缺口集中在「创作页模型配置」「分镜/视频后期能力」「公开内容端」「部分管理端只读面板的写接口」等次要链路上。

## 3. 重点示例：创作页「模型配置」功能点专项

用户点名的功能点，作为本次审查的示例详细展开。

### 3.1 前端现状（apps/web-user/src/pages/HomePage.tsx）

- 入口：工具栏「模型配置」按钮 → `model-config-modal` 弹窗（L.986 / L.1020~1120+）。
- 四个子 Tab：视频 / 角色图片 / 场景图片 / 道具图片。
- 选项全部为 **前端硬编码**：
  - 视频模型：`seedance25 / seedance20 / seedance20fast / klingo3`（L.1050~1055）
  - 分辨率：`480P / 720P / 1080P`；画面比例：`16:9 / 1:1 / 9:16`；时长：`自动 / 1分钟 / 1-2分钟 / …`
  - 图片模型：`luxbanana2` 等（`IMAGE_MODEL_ROWS`，L.56）
- 选中结果仅保存在 **本地 React state**（`videoModel / imageModel / resolution / ratio / videoDuration`），**不落库、不随项目保存、不与生成请求联动**——生成时实际调用的模型由后端任务调度决定，前端选择对生成结果无影响。
- **没有任何请求发出**（无 GET /models、无 PUT 保存）。

### 3.2 后端现状

- ✅ **已提供公开接口**：`GET /models?capability=`（router.go L.184 → `biz_service.go ListModels`，L.85~108），返回 `model_id / model_key / name / capability / provider / cost_points / enabled`，支持按能力过滤（LLM/T2I/I2I/T2V/I2V/AUDIO）。
- ✅ 管理端已可维护模型数据（AdminModelsTab：厂商/模型/密钥 CRUD）。
- ❌ **用户端未接入**：创作页模型配置弹窗未调用该接口，导致：
  1. 模型清单与后端 models 表脱节（硬编码选项可能指向已停用/不存在的模型）；
  2. 管理员在管理端启停/定价模型，用户端不感知；
  3. 选择结果无持久化（不随项目、不随用户偏好保存）。

### 3.3 建议

| 优先级 | 动作 |
| --- | --- |
| P1 | 创作页模型配置弹窗改为调用 `GET /models?capability=T2V/T2I` 渲染选项，按 `enabled` 过滤、`cost_points` 展示积分价 |
| P1 | 分辨率/比例/时长若需服务端约束，挂到平台配置（`/admin/platform/config` 已有 ai_max_video_sec 等 key） |
| P2 | 若选择需随项目生效，扩展现有 `PUT /projects/:id`（config JSON）或项目生成参数透传；当前选择至少应作为生成请求参数上传 |
| P2 | 图片/视频模型选项与 `capability` 枚举（LLM/T2I/I2I/T2V/I2V/AUDIO）对齐，避免硬编码厂商型号 |

## 6. 审查结论与后续动作

### 6.1 已闭环（无需动作）
- 认证、项目/剧本/资产/视频/导出五步创作闭环；
- 积分/订阅/支付、通知（REST + WS）、空间协作、内容广场、任务大厅；
- 管理端：工作台、用户、审核、作品、任务、订单/套餐、平台配置-基础设置、**模型配置（管理侧 CRUD 完整）**。

### 6.2 建议优先补齐（按影响排序）

> 状态：以下 5 项已于 2026-08-20 全部落地（见 §4 状态列）。

1. **创作页模型配置对接 GET /models**（§3.3，用户端最直接可见的缺口）——✅ 弹窗接入 + 偏好持久化（GET/PUT /me/preferences）；
2. 平台配置 4 个只读面板（公告/Banner/限流/主题）补写接口——✅ 已补齐（含积分包/风格库，共 6 个写接口）；
3. 广场页作品详情与互动（后端已就绪）——✅ 详情弹窗 + 点赞/收藏/评论/举报接通；
4. 分镜/视频后期能力接入 Step3/Step4（后端已就绪）——⚠️ 未实施：属于 AI 生成链路大功能，建议独立排期（后端 storyboards/compose-video/tts 接口已就绪）；
5. 支付配置、协议管理、提现审核三个占位 Tab 的产品决策——✅ 支付/协议复用平台配置落地；提现新增表与审核接口落地。
