## 3. 用户发现的问题专项：头像面板修改昵称

- **luxreal**：头像 → profilePanel →「账号设置」→ 可编辑昵称。
- **我们现状**：[ProfilePanel.tsx](file:///d:/develop/a_work/duanju/apps/web-user/src/components/ProfilePanel.tsx) 只有空间列表 + 头像上传 + 退出登录；`PUT /auth/me` 后端已支持 `nickname` 字段（auth/dto.go UpdateMeReq），但前端没有入口。
- **结论**：纯前端缺口，后端就绪。补齐方式：ProfilePanel 增加「账号设置」入口 → 弹窗内昵称编辑（PUT /auth/me）+ 头像上传（已有）。
