## 一、分环节对比

### 1.1 登录 / 注册

| 维度 | LuxReal | 本项目 | 差距 |
|------|---------|--------|------|
| 注册 | 邮箱+昵称+密码，自动登录，**赠 500 初始积分**，无邮箱验证 | register 同链路；注册事务内建个人空间+积分账户+**注册赠送积分（platform_configs.initial_points=500，后台可配）** | ✅ 对齐且更灵活 |
| 登录态 | JWT 2h + HttpOnly Refresh Cookie 7d + 401 自动刷新 + 登出黑名单 | 同构 + **Refresh 绑定 UA/IP 指纹**（更严） | ✅ 领先 |
| 忘记密码 | M0 先做"联系管理员"链接（forgot-password 页） | **无任何实现**（后端无 forgot 端点，前端无入口） | ❌ F1 |
| 限流 | 登录 60/min、未登录 20/min、VIP 提权 | RateLimit 中间件已挂（v1Pub/v1Auth 双层） | ✅ 对齐 |

### 1.2 首页 / 创建项目

| 维度 | LuxReal | 本项目 | 差距 |
|------|---------|--------|------|
| 剧本输入 | 粘贴 + 长文档拖拽上传自动解析 | 粘贴 + **文件上传已实现**（txt/md 直读、docx/pdf 前端解析、.doc 拒绝，presign→MinIO） | ✅ 对齐 |
| 创建配置 | 风格库（27 风格+预览图+自定义）、比例、每集时长（6档可不选=Agent 自动） | 创建弹窗含风格/比例/时长下拉（audit 截图证实） | ⚠️ 风格库规模小，无自定义风格 |
| Agent 技能配置 | 4-Tab 面板全量公开可编辑可另存（一次配置全流程沿用） | `/skills` 仅只读列表，提示词 Go 硬编码 | ❌ F2（=清单01 Q7） |
| 项目卡片 | 重命名/复制/克隆（P1）/归档 | 改名✅ 删除✅ 恢复✅；**复制、导出"即将上线"占位** | ❌ F3 |

### 1.3 Step1 剧本拆分

| 维度 | LuxReal | 本项目 | 差距 |
|------|---------|--------|------|
| 拆分引擎 | 单次 Lux Chat 5.2 出整树 + 智能扩写开关 | 单次 LLM + 确定性后处理（分集/超长/覆盖率校验） | ✅ 架构对齐（细节见清单01） |
| 分集 | 集=用户容器，+新增剧集按钮 | 纯算法分集，无手动建集 | ❌（清单01 Q1/Q2） |
| 单元行内编辑 | 原文/标题/时长可改、上下加单元、删单元 | **前端全部桩点**（"单元编辑/排序/新增/删除将在后续版本开放"）；后端 narrative-units 仅有版本回滚接口，无 PATCH/增删 | ❌ F4（=清单01 Q3） |
| 集级时长预设 | 本集下拉 6 档两级继承 | 项目级单值；Step1 设置条"时长策略"为桩 | ❌（清单01 Q2） |
| 设置条生效 | 风格/比例/时长一次配置全流程沿用 | Step1 设置条**分辨率/画幅/风格/时长策略 4 个 chip 全为桩**（点击仅 toast） | ❌ F5 |
| 重拆 | 失败手动重触发，有资产时级联清空二次确认 | split-script + 重拆已实现（含覆盖保护） | ✅ 对齐 |

### 1.4 Step2 资产生成

## 三、总体评价

1. **骨架对齐度高**：四步流水线、单次拆分成树、冻结-结算计费、WS 推送、版本回滚——架构层与 LuxReal 同构，鉴权/注册赠分/文件上传等处还更细；
2. **最大问题是"前端桩点密度"**：全项目 25+ 处"将在后续版本开放"toast，界面看起来功能齐全实则不可用——其中 **F10 参考图机制是唯一影响出片一致性的结构性缺口**，其余多为交互精修类；
3. **后端普遍领先前端**：variants、narrative-units 版本、PATCH 资产、concat-video、shots/batch 等接口已就绪但前端未接线（F6/F8 属"纯接线"工作，投入产出比最高）；
4. **有意保留的差异**：3D 片场（依赖群核底座）、标记语法输出契约（我们 JSON 更硬）、数学粒度铁律（无人工精修 UI 时的保底）——不对齐是正确的。

### 实施顺序建议

```
第一批（低成本高收益，纯接线）：F6 提示词编辑 → F8 添加造型 → F1 忘记密码
第二批（结构性补齐）：F10 参考图绑定 → F11 单镜头重生成 → F7 上传替换
第三批（精修能力，与清单01 Q1~Q4 合并）：F4/F9/F5/F3
第四批（P2 观察）：F12/F14/F13/F15/F2/F16/F17
```
