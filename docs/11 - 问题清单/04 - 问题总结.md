## 三、有意不对齐项（保留差异，勿当问题修）

| 项 | 理由 |
|----|------|
| 3D 片场 | 依赖群核自研 3D 底座，不可复制（报告 8.1） |
| 标记语法输出契约（【场景X】/▲） | 我方 JSON schema + 枚举校验更硬，是优势 |
| 数学粒度铁律（4字/秒、≤30s、≤120字） | 无人工精修 UI 时的保底；待 F4/Q3 落地后再评估放松 |
| 确定性后处理分集 | 等价于 LuxReal"手动建集兜底"的自动化版本 |
| 导出 4K | 厂商模型与成本限制 |
