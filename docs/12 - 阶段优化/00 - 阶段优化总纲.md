## 一、审查与对齐

### 1.1 审查工作思路（落地版）

| 层面 | 代码视角 | 安全角度 | 可用性角度 |

## 二、业务流程梳理

### 2.0 主流程总览（五步，实测接口链路）

```
上传剧本(Home) → 剧本拆分(Step1) → 资产提取与生成(Step2) → 视频制作(Step3) → 成品合成预览(Step4)
        ↓ 横切：积分扣费/冻结-解冻 · WS 实时推送 · 任务队列 worker · 空间/团队口径
```

### 2.1 创建项目 / 上传剧本

- **前端**：HomePage 支持 txt/md/docx/pdf 上传（presign → MinIO 直传 ✅）+ 正文粘贴输入框
- **后端**：`POST /projects`（title/script_file_asset_id/episode_duration_min 等）→ 项目 DRAFT
- **交互时序**：进入工作台后后端开始处理，前端进入等待态（WS 订阅）
- ⚠️ UI 修改点：上传后输入框**不需要小说内容预览**（见三章 U1）

### 2.2 剧本拆分与资产自动化提取（Step1）

- **前端**：加载剧集列表 + 第一集的叙事单元列表；顶部设置条（风格/比例/分辨率/时长策略）
- **后端链路**：`POST /projects/:id/split-script` → 任务入队 → worker `split_handler`：单次 LLM（禁用思考模式）+ 确定性后处理（NormalizeEpisodeCount/SplitOversizedUnits/mergeTinyEpisodes）→ 拆分完成后推进**资产自动化提取**（角色/场景/道具三类）
- **实体**：project → episode（集）→ narrative_unit（叙事单元，≤30s 铁律）→ beat
- ⚠️ 差距：Q1 手动建集、Q2 集级时长预设、Q4 单单元重拆、F4 行内编辑（见清单 01/03）

### 2.3 资产生成（Step2，多形象）

- **后端**：`POST /assets/batch-generate`（集级批量）；`GET/POST /characters/:id/variants`（**多形象后端已就绪**）；`PATCH /characters|scenes|props/:id`；`POST /assets/:id/derive`（派生）
- **计费**：`POST /points/preview` 预检 → 冻结 → 成功解冻扣费/部分失败回退（ENUM: BATCH_GEN_FREEZE/UNFREEZE_*）
- ⚠️ 差距：F6 提示词编辑桩（后端 PATCH 已有，纯接线）、F7 上传替换缺失、F8 添加造型桩（后端就绪）、F9 重新提取本集资产
- 🆕 需求：角色支持**三视图**（正/侧/背）+ 多形象（见三章 U4）

### 2.4 视频制作（Step3，分镜描述词 + 资产参考图 + 技能包）

- **后端**：`POST /beats/:beat_id/generate-videos`（beat 级批量）、`POST /beats/:id/storyboards/generate`（分镜图）、`shots/batch`、`beats/:id/replan`
- **技能包链路**：Agent 技能（拆分/分镜/润色）→ 模型路由（provider/key 池，429/5xx 自动切 Key）→ 任务队列
- ⚠️ **最大结构性缺口 F10**：镜头↔资产参考图绑定完全缺失（chips 为占位色块）——LuxReal 一致性的根基；F11 仅 beat 级生成，单镜头重生成桩（后端 shots/batch 已有雏形）

### 2.5 视频合成（Step4，成片）

- **后端现状**：`POST /shot-groups/:id/concat-video`（块内拼接）、`beats/:id/compose-video`、`POST /exports`（P480/P720/P1080）
- 🔴 **关键事实**：`export_handler` 目前是 **mock 合成**（模拟 FFmpeg concat），导出 30 天有效期
- 🆕 需求：**视频合成放模型服务器**（GPU worker 真实 FFmpeg 管线；与 R 系列部署项一起做）
- ⚠️ 差距：F13 选段合成、F14 LXP 工程包、F15 片头片尾（P2）

### 2.6 支付（横切，新增完善项）

- **现状**：套餐/积分包/订单/提现全链路后端已实现（packages/point-packages/orders/withdrawals）；`pay_mock_enabled` 沙箱开关存在
- 🆕 需求：**对接微信支付 + 支付宝真实网关**；套餐页面增加**积分充值**档位入口
- ⚠️ 前置：A6 支付配置面板接线（可复用 platform/config）、G1 幂等键（支付回调去重必需）、G3 积分有效期决策

### 2.7 实体与管理抽取（对齐用）

| 实体 | 归属 | 关键关系 | 管理面 |
|------|------|---------|--------|
| user / space | 用户/团队 | space_members 六档角色 | 管理端用户页 ✅；空间页缺（A4） |
| project → episode → narrative_unit → beat | 空间 | 逐层级联；版本回滚接口已有 | 前端精修桩（F4） |
| asset（character/scene/prop）+ variant | 项目/集 | **资产索引须按"剧集+叙事单元"精确寻址资产及对应形象**（U5） | episodes/:id/assets/overview 已有 |
| shot / storyboard | beat | shot↔asset 参考图绑定（F10 待建） | Step3 |
| task / order / point_transaction | 用户/空间 | 冻结-解冻-回退幂等 ✅；操作者归因 ✅ | 管理端任务页/计费页 ✅ |
| export_record | 项目 | 30 天过期（G5 决策项） | Step4 |
| withdrawal / report / audit_log | 平台 | 提现审核 ✅；举报/审计前端缺（A2/A3） | 管理端待补 |
