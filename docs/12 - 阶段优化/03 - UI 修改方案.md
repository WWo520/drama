# 03 - UI 修改方案（对应需求清单 U1~U8）

> 创建日期：2026-08-22
> 定位：承接用户提出创作页 UI 需求（自由画布开发中、上传预览隐藏、按钮高度对齐），落实为可执行的前端改动 + CSS 规范。

---

## 一、需求背景与设计原则

| # | 需求 | 现状 | 目标 | 设计原则 |
|---|------|------|------|----------|
| U1 | 上传后输入框不需要小说内容预览 | 解析 docx/pdf/txt 后自动 `setScript(text)` 回填 textarea，用户可见全文 | 文件已上传时 textarea 显示为空/占位，但内部保留文本供创建项目 | 不丢弃数据（script 仍持有），仅隐藏展示 |
| U2 | 输入框下方按钮组高度对齐 | `.toolbar-pill` padding=7px 14px ≈32px 高，`.btn-enter` padding=8px 20px ≈34px 高 → 视觉错 | 统一高度 36px，用 padding 0+left/right 维持内边距 | CSS 原子化：固定高度 + box-sizing:border-box |
| U3 | 自由画布开发中 | 当前点击“自由画布”tab 直接 `navigate("/canvas")` → 前端无 CanvasPage 路由会 404 | 点击显示 toast "开发中，敬请期待"，badge Beta→开发中，不触发导航 | UX 友好占位，避免 404 |

- 创建项目时 title 取自 script.slice(0,20) → 不受影响

### U2 按钮组高度对齐

**改动文件**: `apps/web-user/src/pages/home.css`

**`.toolbar-pill`**（原 Line 324）:
```css
.toolbar-pill {
  display: inline-flex;
  align-items: center;
  gap: 5px;
  background: rgba(255,255,255,0.07);
  border: 1px solid transparent;
  border-radius: 38px;
- padding: 7px 14px;
+ height: 36px;
+ padding: 0 14px;
  font-size: 13px;
  ...
+ box-sizing: border-box; /* 关键：height 包含 padding */
}
```

**`.btn-enter`**（原 Line 376）:
```css
.btn-enter {
  display: inline-flex;
  align-items: center;
  gap: 6px;
  background: linear-gradient(135deg, #4C7FF8, #3B6CE0);
  color: white;
  border: 1px solid rgba(255,255,255,0.15);
  border-radius: 38px;
- padding: 8px 20px;
+ height: 36px;
+ padding: 0 20px;
  font-size: 13px;
  font-weight: 600;
  ...
+ box-sizing: border-box; /* 关键：height 包含 padding */
}
```

**原理**:
- 原先 `padding:7px 14px`（上下内边距）+ font-size*line-height ≈32px，`.btn-enter` `padding:8px 20px`≈34px
- 改用固定 `height:36px` + `padding:0 14px`（左右内边距），字体行高由浏览器居中渲染，两者视觉对齐
- `box-sizing:border-box`确保高度计算包含 border+padding，而非内容区域
