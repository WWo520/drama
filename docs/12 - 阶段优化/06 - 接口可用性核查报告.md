## 四、规范性检查清单

| 检查项 | 标准 | 实际 | 偏差 |
|--------|------|------|------|
| RESTful 路径 | GET/POST/PUT/PATCH/DELETE 明确语义 | ✅ 全部一致 | 无 |
| 幂等键 | Order/Webhook/Task/Asset 必须有 | ✅ 全覆盖 | 无 |
| 鉴权 | JWT + RBAC 分层 | ✅ adminMW/auditMW/v1Auth/v1Pub | 无 |
| 错误码 | httpx.Fail(code/message/data/request_id) | ✅ 包裹率 100% | 无 |
| 分页钳制 | page≥1 && pageSize≤50 | ✅ store 层统一封装 | 无 |
| 事务原子 | Freeze/Settle/Admin 高危操作 | ✅ M10/M11+R10 强化 | 无 |
| 审计日志 | Admin 高危操作必有 audit_logs | ⚠️ A3 待补审计页面但后端 INSERT 已就绪 | 低风险 |

## 五、已知风险与缓解措施

| 风险项 | 影响范围 | 优先级 | 缓解措施 |

## 六、工具链固化建议

1. **scripts/api-inventory.js**（已存在） → CI 门禁：
   ```bash
   node scripts/api-inventory.js > tmp_report.json
   node -e "const r=require('./tmp_report.json'); process.exit(r.stats.missing>0?1:0)" || echo "前端缺失数=r.stats.missing"
   ```
2. **合同校验升级**（R9 跟进）：
   - 递归扫描所有 `internal/domain/**/*.go` handler 文件
   - HTTP 方法参与匹配（GET POST PUT PATCH DELETE）
   - 模板路径归一化（`${param}` → `:id`）
3. **定期生成快照**（每周/每次大版本）：
   - `backend_routes_YYYYMMDD.txt`（完整路由表）
   - `frontend_calls_YYYYMMDD.txt`（前端调用聚类）
   - 差分报告自动生成（对比历史）

## 七、附录：自动化验证脚本

```javascript
// scripts/api-inventory-validate.js (待落地)
const { execSync } = require("child_process");
const fs = require("fs");

try {
  execSync("node scripts/api-inventory.js", { stdio: "inherit" });
  const report = JSON.parse(fs.readFileSync("tmp_align_report.json"));
  console.log(`✅ 前端缺失数：${report.stats.missing}`);
  if (report.stats.missing > 0) {
    console.error("❌ 存在悬空调用，请修复后重试");
    process.exit(1);
  }
  console.log("✅ 接口可用性核查通过");
} catch (err) {
  console.error(err);
  process.exit(1);
}
```
