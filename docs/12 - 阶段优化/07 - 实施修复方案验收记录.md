## 四、附件：CI 门禁脚本草案

```yaml
# .github/workflows/api-contract-check.yml
name: API Contract Check
on: [push, pull_request]
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - run: pnpm install --frozen-lockfile
      - name: Generate contract report
        run: node scripts/api-inventory.js > tmp_report.json
      - name: Validate no missing endpoints
        run: node -e "const r=require('./tmp_report.json'); process.exit(r.stats.missing>0?1:0)" || exit 1
      - name: Attach report to PR
        uses: actions/upload-artifact@v4
        with:
          name: api-contract-report
          path: tmp_report.json
```
