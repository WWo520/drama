# 资产详情弹窗全量对齐 LuxReal

## 背景
LuxReal 点击资产卡片主图弹出详情弹窗（调查截图 `luxreal_assets_*.png`）。我们当前点击主图无反应，仅有"编辑提示词/重新生成"文字按钮。全量对齐其弹窗全部功能。

## 提示词机制（对齐 LuxReal 六层机制）
1. 拆分预生成默认提示词（已有 `description_notes/base_prompt/description_prompt`）
2. 弹窗可编辑 → 新增 `edited_prompt` 列（NULL=未编辑）
3. "恢复默认提示词" → 清空 `edited_prompt`
4. ✨AI优化 → LLM 重写接口
5. "+"参考图 → `ref_image_ids` 参与生成
6. "修改图片"=图改图 → 主图自动设为参考图

## 后端改动（duanju-backend）

### 迁移 000050_asset_dialog_align.up.sql
- `characters/scenes/props` 各加 `edited_prompt TEXT NULL`
- `generated_images` 加：`is_favorite BOOLEAN NOT NULL DEFAULT FALSE`、`target_kind VARCHAR(24) NULL`、`target_id BIGINT NULL`、`model_code VARCHAR(64) NULL`、`style_name VARCHAR(64) NULL`、`aspect_ratio VARCHAR(8) NULL`、`use_default_composition BOOLEAN NOT NULL DEFAULT FALSE`
- 执行迁移（psql 直连，避免只写文件不执行）

### 新接口（asset_detail_service.go 扩展）
| 路由 | 功能 |
|---|---|
| PUT /assets/:kind/:target_id/prompt | 更新 edited_prompt |
| POST /assets/:kind/:target_id/prompt/reset | 恢复默认（清空 edited_prompt） |
| POST /assets/:kind/:target_id/prompt/optimize | AI优化（LLM 重写精简，复用 DeepSeek 引擎） |
| GET /assets/:kind/:target_id/history | 生成历史（?favorite=1 过滤收藏） |
| POST /generated-images/:id/favorite | 收藏/取消 |
| POST /assets/:kind/:target_id/upload | 替换/导入图片（multipart→S3→更新主图+写历史） |
| POST /assets/:kind/:target_id/generate | 单目标生成（带全参数） |

### 生成参数透传
- `BatchGenerateReq`/单生成 payload_json 增加：prompt、model_code、style_name、aspect_ratio、resolution、use_default_composition、ref_image_ids
- `asset_handler.go` 消费时优先用 payload 的 prompt/参考图（dev 仍 mock 降级）
- 生成成功写 generated_images 时记录 target_kind/target_id/参数/收藏默认 false

## 前端改动（web-user）

### 新组件 AssetDetailDialog.tsx（对齐截图结构）
- 顶部：名称+编辑、变体 tab（角色，含+创建新形象）、关闭
- 主图区：主图徽章/收藏星/下载、添加音色（角色占位 toast）、替换/重新编辑/修改图片
- 提示词区：+参考图菜单（本地上传）、可编辑 textarea、"恢复默认提示词"链接（编辑后显示）
- 底部工具栏：使用默认构图勾选（角色）、模型下拉（model_providers 真源）、风格下拉（27 项公共库常量）、比例/分辨率、✨AI优化、生成按钮（积分）
- 右侧生成历史：卡片/列表切换、我的收藏勾选、+导入、列表项"重新编辑/重新生成"

### Step2Page.tsx
- 三类卡片主图 onClick → 打开 AssetDetailDialog(kind, target_id)
- 移除原"编辑提示词"文字按钮（功能并入弹窗）

## 验收
1. 点击角色卡片主图 → 弹窗与 LuxReal 截图结构一致
2. 编辑提示词 → 生成用编辑值；点恢复默认 → 回拆分原值
3. ✨AI优化 → 提示词被 LLM 重写
4. 变体 tab 切换 → 主图/提示词/历史独立；创建新形象 → 新 tab
5. 生成 → 历史出现新卡片；收藏/列表模式/导入可用
6. 修改图片 → 主图变参考图 chip 进入图改图
7. tsc 零错误 + go build/vet 通过 + 浏览器实测截图
